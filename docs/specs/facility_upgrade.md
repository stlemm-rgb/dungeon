# 시설 강화 — 한 쪽 기획서 초안

> 2026-10-24 · 사용자 결정 전. 아래 동작·추가 숫자는 **제안**이며, 8절 추천안을 기준으로 썼다.
> 근거: FEATURES·GAME_PLAN 마지막 절·HANDOFF, DESIGN_D1_DOORS 12절, D1 battle_data.js·API 13절, 새_게임_청사진. 시설 기본 비용·피해는 zones.js에서 추가 확인.

## 1. 왜

매주 전투를 보고, 잘 쓰인 함정을 강화할지 다른 길에 시설을 더 지을지 고른다.
문으로 침입자를 유도한 뒤 투자 효과를 확인하며, 첫 현장의 넉넉한 마석으로 실패 부담 없이 다시 배치한다.

## 2. 플레이어가 하는 것

1. 전투 결과의 함정 퇴각·대기실 격퇴 요약을 보고 현장으로 간다.
2. [건설]을 누르기 전, 지어진 함정이나 대기실을 눌러 강화 화면을 연다.
3. 현재 → 다음 효과, 비용·남을 마석, 예상 전투력 변화를 보고 강화·새 건설·문 변경 중 고른다.
4. [강화]를 누르면 즉시 반영한다. 닫기만 하면 아무것도 쓰지 않는다.
5. 홈의 [다음 주]로 전투를 보고 선택을 다시 판단한다. 매주 강화를 강제하지 않는다.

## 3. 규칙

- **제안:** 함정은 피해, 대기실은 그 방에 출진한 부대·친위대의 전투 체력만 높인다. 자리·공격·발동 확률·길 찾기는 그대로다. 빈 대기실은 전투 효과가 없다.
- **제안:** 대기실 보너스는 전투 시작 때 적용하며 군단 원래 능력치나 영구 성장에 더하지 않는다. 전투 중 저장을 불러와도 다시 더하지 않는다.
- **제안:** 강화는 마석을 쓰며 시간은 흐르지 않는다. 전투 중·미확정 시설·잠긴 층·고정 구역·빈 방·미끼·입구·보물방은 강화할 수 없다.
- **제안:** 강화 수치는 실제 전투와 예상 전투력에 함께 반영한다. 통과 비율·함정 재방문 제한을 유지하고, 시설 가치에는 강화 보너스를 붙이지 않는다. 전투력이 바뀌면 납품 조건·침입자 예고도 다시 계산한다.
- **제안:** 문만 옮기면 강화는 유지한다. 시설 교체·철거 확정 때 강화는 지우고 실제 낸 강화 마석만 전액 돌려준다. 기존 건설 비용 규칙은 별도 유지한다. 미확정 배치 취소에는 환급도 없다.
- **제안:** 새 위치에는 새 시설을 짓고 다시 강화한다. 확정 시설을 통째로 끌어 옮기는 기능은 추가하지 않는다. 환급·재건으로 무료 부대를 더 받는 일도 없어야 한다.
- **제안:** 납품하면 강화된 시설도 현장과 함께 인계한다. 다음 현장·친위대에는 강화 효과나 강화비를 넘기지 않는다.

## 5. 화면

**제안:** [현장] 기본 화면에서 시설을 누르면 판 위로 아래쪽 상세 창을 연다. 방 이름·시설·단계, 효과 전후, 마석 비용과 잔액, 예상 전투력 전후를 보이고 [강화]·[닫기]를 둔다. 대기실은 출진 부대와 “이 방에서만 적용”을 표시한다.
**제안:** 지나갈 가능성이 낮은 방에는 “문 배치부터 바꿔 보세요”를 표시한다. 예상치는 확정 결과가 아님을 알리고 일반 화면에는 경로 선을 추가하지 않는다. 부족한 마석·최고 단계는 버튼 옆에 이유를 쓴다. 강화 후 창과 판의 단계 표시를 함께 갱신한다.
**제안:** 건설 모드의 끌기와 강화 누르기를 섞지 않는다. 시설 교체 미리보기에는 사라질 강화와 환급액을 표시한다. 휴대폰에서도 선택한 방과 닫기·강화 버튼을 확인할 수 있게 한다.

## 6. 데모 범위

- **이번 제안:** 함정·대기실의 단순 단계 강화, 미리보기·마석 차감·교체 환급·저장·납품 처리. 첫 현장에서 확인하고, 두 번째 현장 공개 때 열린 층에도 같은 규칙 적용. 현재 q2는 숨김이며 이 기능만으로 열지 않는다.
- **안 할 것:** 강화 가지 선택, 새 재화, 특수 효과·자리 확장, 연구실·영구 시설 성장, 방 합치기, 새 일러스트, 스토리·튜토리얼 대본. 숫자 확정과 전체 밸런스 작업은 측정 뒤로 둔다.

## 7. 끝 기준

- **규칙 검사:** 비용·효과·상한, 마석 부족·잘못된 대상·전투 중 거절, 닫기 무변경, 빠른 연속 누르기로 중복 차감 없음. 미리보기와 확정 결과가 같고 가치 보너스는 없다.
- **연결 검사:** 문만 변경 시 강화 유지, 교체 취소 무변경·확정 시 실제 지출만 한 번 환급, 무료 부대 중복 지급 없음. 경로·함정 진입 제한 유지, 강화된 피해·체력과 납품 전투력 계산 일치.
- **저장 검사:** 새로고침·전투 이어하기에서 효과 중복 없음. 강화 항목 없는 기존 v7 저장은 기본 단계로 읽고 현장 진행 보존. 납품 뒤 새 현장과 친위대에 보너스가 남지 않음.
- **화면 검사:** 390px 폭에서 열기→미리보기→강화→닫기→다음 주 가능, 가로 넘침·콘솔 오류 없음. 향후 구현 완료 때 D1 검사와 `py tools/check_all.py` 통과.
- **재미 확인:** 같은 시드들로 강화 위주·새 시설 위주·문 변경 병행을 비교해 납품 주차·퇴각/격퇴·마석 잔액을 기록한다. 사용자가 전투 뒤 다음 배치를 바꿀 이유를 설명할 수 있는지 확인한다. 강화 연타나 다음 주 연타만 남으면 완료로 보지 않는다.

## 9. 위험

강화만으로 풀리면 문 퍼즐이 사라진다. 같은 마석으로 문·시설 배치를 바꾼 결과와 반드시 비교한다.
이미 강한 대기실은 소폭 강화도 쓸모없거나 격차만 키울 수 있다. 효과가 없으면 항목을 재검토하고 수치만 키우지 않는다.
넉넉한 마석이 즉시 납품을 만들거나, 환급이 무한 재화·부대 지급을 만들 수 있다. 진행 길이는 강화 대기시간으로 억지로 늘리지 않는다.
