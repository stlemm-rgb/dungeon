**데모 추천 4개와 이유** — 단계는 추천이며 사용자가 정한다.
- 시설 강화: 이미 지은 시설을 다시 누를 이유를 만들고, 사용자가 남긴 다음 선택을 확인한다.
- 건설판 가시성: 문을 옮기며 판을 보는 핵심 조작을 작은 휴대폰에서도 판단하기 쉽게 한다.
- 튜토리얼 동선: 결과표에서 [홈으로]를 찾게 해 첫 의뢰 루프가 안내 도중 끊기지 않게 한다.
- 전투 결과 설명: 경로와 결과의 관계를 한 줄로 알려 다음 배치를 바꿀 근거를 준다.

**사용자가 정할 것**
- 시설 강화는 무엇을 올리고, 어떤 재화로 하며, 납품 뒤 무엇이 남나?
- 데모는 현재처럼 첫 의뢰에서 끝내고 2층·q2 공개는 출시로 둘까?
- 방 합치기를 시설 강화 다음에 시험할까, 2층 확장 다음에 시험할까?
- 경험치 책·훈련 교본은 즉시 경험치와 다음 참여 강화 중 어떻게 나눌까?
- 출시 최소 범위에 내 집·지점까지 넣을까, 의뢰·건설·군단 성장부터 완성할까?
