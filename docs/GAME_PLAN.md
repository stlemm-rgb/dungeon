| 판 크기 | 줄임. 시안 A3·A4는 가로 5 × 세로 7 |
| 공터·집결지 (시안 A4) | 맨 윗줄은 던전 밖 공터(못 지음). 입구 칸은 모험가가 모여 처음 나타나는 집결지 (나중에 모험가를 실제로 배치할 곳) |

| 문 (시안 A4) | **칸 하나의 변에 문 1개**. 방을 만들면 문 **2개**(들어오는 문 + 나가는 문)가 길이 이어지게 자동으로 생김. 이후는 유저가 직접: **방 벽의 옅은 칸(문 자리)을 누르면 문이 생김**(조건: 그 방·옆 방의 문이 4개 미만, 벽 바깥이 통로나 다른 방), **문을 누르면 없어짐**(조건: 없애도 입구~보물방 길이 이어짐), **끌면 옮김**. 길이 바뀌어 문이 원래 수보다 줄면 자동으로 채움 |
| 길 표시 | 침입자가 지금 올 가장 짧은 길을 판 위에 점으로 표시 (Codex 개선안에서 가져옴). 그 길에 없는 방은 흐리게 "안 지나감" |
| 기본 통로 | 고리 모양 (위·왼쪽·오른쪽·아래). 가운데 직선 길은 뺌 — 있으면 길 옆에 지은 방을 침입자가 그냥 지나쳐서 첫 배치가 무의미했음 (플레이 시험 1회차) |

| 특수 방 | 미리 정해진 모양의 큰 방, 방 만들기에서 고름. **2×2 미로**(헤매느라 보급 소모, **문 최대 2개**, 일반 방과도 이어짐), 2×2 보스방(퇴각 없이 끝장 승부, 층마다 1개). 나중에 보상·해금 대상으로 쓰기 좋음 |
| 출구(문) | 침입자는 문으로만 방을 드나듦. 문이 적을수록 침입자에게 유리한 효과(미정), 대신 유저는 방향을 고정할 수 있음. 무작위 진행은 문 하나당 같은 확률 |
| 되돌아가기 | 침입자는 방을 지난 뒤 **들어온 문으로 되돌아가지 않음**. 되돌아가는 건 피해가 클 때(퇴각)뿐. 그래서 갈림길(문 많은 방)이 많을수록 많이 헤매고, 갈림길이 없는 일직선 던전에서는 헤매지 않음 (시안 A4에 넣음) |
| 침입 화면 | 침입 중에도 일시정지·계속·중단·속도 바꾸기 가능 |
| 재진입 금지 | 침입자는 방금 나온 방으로 곧바로 다시 들어가지 않음 (다른 길이 없을 때만 예외) |
| 침입자 움직임 | **퇴각**: 방에서 지면 들어온 문으로 되돌아감. 그 뒤 다른 길로 다시 들어와 계속 공략할 수 있음. **돌파**: 방을 클리어했거나 침입자 수가 그 방 몬스터 부대 수보다 많으면 방의 출구 중 하나로 무작위 진행(출구 3개면 각 1/3). **도주**: 공략 의지나 장비가 바닥나면 가장 짧은 길로 입구까지 도망. 결과창에 도망친 수 표시 |
| 큰 방 | 크기 = 수용량. 몬스터 방은 칸 수만큼 부대, 함정 방은 칸 수만큼 함정 |
| 길 규칙 | 1층 던전은 입구에서 보물방까지 길이 적어도 하나 이어져 있어야 함 (완전히 막는 배치는 불가) |
| 여러 층 | 2·3층 던전은 보물방 자리에 아래층 계단 |
| 나중에 | 벽을 뚫고 일직선으로 돌파하는 침입자 |
| 진행 순서 | 설정을 더 다듬기 전에 핵심 퍼즐 재미부터 프로토타입으로 확인. 컨셉 질문은 시안 뒤에 이어서 |

### 전투 흐름
1. **전투 화면 들어감**: 처음엔 멈춘 상태. **"전투 시작" 버튼은 홈의 "다음 주" 버튼 자리**에 있다.
2. **등장**: 전투를 시작하면 침입자 무리가 **대기 장소에 하나씩 차례로** 나타난다. **등급이 낮은 무리부터, 가장 높은 무리가 마지막.** 나타날 때마다 아래에 안내가 올라온다. 예: "XX 왕국 XX 기사단 N명 평균 레벨 20", "황금 XXX 모험단 N명 평균 레벨 22", "동방 순례자 N명 평균 레벨 24", "마을 약초 채집꾼 N명 평균 레벨 29". 등급 체계는 나중에 정함.
3. **침입자 카드**: 가장 높은 등급 무리가 나타나면 **침입자 카드**가 떠서 그 무리의 효과가 확정된다. 예: 성기사단 S랭크(침입자 전체 공격력 +10%, 방어력 +20%), 함정 해체꾼(함정 발동 확률 -90%). 알려 주는 것은 **플레이어의 비서**가 맡는다.
4. **진입**: 그 다음 침입자들이 던전에 들어온다. **10명이 한 분대**이고, 분대는 아주 작은 **얼굴 도트**로 움직인다. 정해진 이동 규칙대로 유저가 지은 던전을 지나간다.
5. **이벤트 카드**: 돌파 진행도 **15 · 30 · 45 · 60**마다 이벤트 카드가 뜬다. 침입자를 막는 데 도움이 되는 버프. 예: 함정 수리(함정 효과·발동 속도 증가), 몬스터 버프(전투력 증가). 카드는 **위·아래·왼쪽·오른쪽 4방향**으로 밀어 효과를 고른다. 카드마다 4방향 효과가 다르고, 한눈에 알아볼 수 있게 적는다.
6. **결과**: 막아 내거나, **보물방까지 뚫리면** 침입 결과표를 보여 준다. 잡은 적에게서 얻은 금과 보물방에 들어온 적의 수를 합산.

- **침입자**: 용사, 모험가, 팔라딘, 군대, 환생자, 빙의자 등. 판타지와 웹소설 클리셰 느낌.
- **몬스터 부대**: 몬스터 이름, 그림, 인원수, 전투력(여러 수치의 합), 특성, 장비. 던전 가치에 포함. 인계 불가 (친위대만 예외).
- **몬스터 부대장**: 캐릭터 (예: 라미아 무녀). 전투력, 스킬, 특성, 장비(강화·교체 가능), 호감도, 성장. 던전 가치에는 미포함이지만 가치를 올리는 데 도움. 인계 가능.
- **특별 몬스터**: 내용 미정.
- **랭킹**: 부문별. 예) 가장 가치 높은 던전, 함정 100% 던전 중 가치 순위, 공허 속성 몬스터로만 만든 던전 중 가치 순위.
- **화면**: 시작, 홈, 던전(처음엔 1층, 난이도에 따라 층 증가, 부대 배치·미로·함정 설치), 부대, 전투(턴 진행 시 화면 전환, 미끼(보물·인질·포로)로 유인, 지도형 던전에 입구로 침입, 아래쪽에 개입 카드), 스토리 전용(배경 그림 필요).
- **스토리**: 화면을 진행하다 조건이 맞으면 나옴. 캐릭터 + 자막, 나레이션, 자막만 등 여러 방식.
- **미정**: 함정·미로·부대를 얻는 방법과 확인 화면, 카드를 얻는 방법·강화·등급.

## 총괄 제안 (검토 중)
- **던전 가치** = 시설(함정·미로·층) + 몬스터 부대 + 방어 실적 보너스. 부대장은 스킬로 가치를 올림.
- **침입자의 역할**: 던전 시험 + 자원 수입(전리품, 포로, 경험치).
- **부대장과 부대**: 부대장 1명이 부대 N개를 지휘. 지휘받지 못한 부대는 약해짐.
- **마왕 만족도**: 방문 때의 반응으로 오르내리고, 판매가와 다음 의뢰에 영향.
- **조건 엔진 하나**: 마왕 요구, 랭킹 부문, 스토리 조건, 업적을 같은 조건 목록(data/)으로 처리.
- **저장 나누기**: `meta`(회차가 바뀌어도 남는 것)와 `run`(이번 회차).
- **미끼가 손님을 바꿈**: 보물 → 모험가, 인질 → 용사·팔라딘, 포로 → 구출대·군대.
- **침입자마다 특징 하나**: 환생자는 함정 위치를 앎, 빙의자는 부대장을 흔듦, 군대는 숫자가 많음, 팔라딘은 어둠·공허에 강함.
- **부익부 브레이크**: 회차가 오를수록 요구가 높아짐. 랭킹에 제한 부문(예: 부대장 3명 이하).
- **추가 화면**: 의뢰서, 납품·감정 결과, 회차 정산, 뽑기, 랭킹, 도감, 설정. 아래 탭 메뉴.
- **화풍**: 일찍 정하기. 도트 그림 추천.
- **명성과 미끼**: 명성(영구 성장 수치)이 오르면 침입자 등급이 자동으로 오르고 보상도 커짐. 미끼는 그 턴의 위험과 보상 선택. 장마다 명성 상한, 마왕 던전을 납품하면 상한이 풀림.
- **회차 이득 3종**: ① 승진(사원→대리→과장→현장 소장→이사, 직급마다 친위대 칸·층 수·카드 칸 같은 기능 해금) ② 자격증(회차 정산 때 영구 보너스 3개 중 1개 고르기) ③ 설계도 보관(완성한 던전 배치를 저장해 다음 회차 시작 때 일부 불러오기).
- **속성별 요구 조건 예시**: 화염 = 화염 함정 비율, 공허 = 공허 몬스터만, 크툴루 = 광기 수치, 공포 = 침입자를 도망치게 만든 횟수, 괴담 = "○○하면 안 된다" 같은 규칙형 조건.
- **사천왕의 역할**: 의뢰인은 아니지만 짓는 동안 방문 캐릭터(훈수, 시험)로 등장할 수 있음. 배신 사건의 주인공.
- **유지보수 미니게임**: 2~3종만 (예: 함정 수리 타이밍, 미로 길 잇기). 3단계 이후.
- **무한 모드**: 마왕과 사천왕 속성을 무작위로 조합하고 난이도가 계속 오름. 랭킹의 주 무대.

## 2단계 최소 범위 (가장 작은 한 바퀴)
| 넣는 것 | 빼는 것 (3단계 이후) |
| --- | --- |
| 마왕 1명, 의뢰 2종 | 뽑기, 광고 |
| 1층 던전, 함정 2종, 미로 1종 | 카드 |
| 몬스터 부대 3종, 부대장 1명 | 온라인 랭킹 |
| 침입자 2종 (모험가, 용사), 미끼 1종 | 스토리 화면, 배경 그림 |
| 자동 전투 + 결과 표시 | 호감도 이벤트, 여러 층 |
| 납품 → 감정 → 회차 정산 (친위대 1명) | 그림 (네모와 글자로 대신) |
