# 게임 큰 틀: 하단 탭 × 입구 (확정 2026-10-22)

## 1. 하단 탭 5개 × 입구
| 탭 | 화면 | 입구 |
| --- | --- | --- |
| ① 회사 (홈) | 하청 건설사 건물 단면 | 의뢰 게시판 · 작품집(데모) · 비서실(보상 한 번에 받기) · 응접실 · 소장실 · 직원실 |
| ② 군단 | 부족 목록 하나(화면 안 구분) | 부족(모집·보석 강화) · 친위대 · 훈련(경험치 책·훈련 교본) · 대장간 · 몬스터 숙소 |
| ③ 현장 | 세로 지하 단면. 맨 위 **다음 주 버튼**(언제든), 그 아래 **의뢰 진행표 고정**(목표·남은 예산) | 건설 · 출진 · 포로 수용소. **납품은 목표를 다 채우면 진행표가 "의뢰 완료"로 바뀌며 거기서 바로** |
| ④ 마계 | 마계 지도 | 지역(포탈) · 작품집 거리(로열티·증축 투자·소식) · 지점 · 모험가 길드 · 라이벌 건설사 · 행사장 |
| ⑤ 내 집 | 저택 + 부대장 마을 | 저택 · 부대장 집 · 식당·주점 · 진열장 |
- **탭 순서(사용자 10-22): 회사 · 군단 · 현장(가운데) · 마계 · 내 집.** 특정 탭만 튀는 강조(노란 원 등) 없이 모두 같은 모양.
- **납품(사용자 10-22)**: 기한이 없으므로 의뢰 목표를 다 달성하면 의뢰 완료처럼 진행표 상단에 고정 표시 → 납품. **납품 완료 화면에서 던전 속성마다 다른 던전 모습(물리 = 돌 성채, 얼음 = 얼음 첨탑, 불 = 용암 동굴 등)이 나오며 성공 연출.**
- 상점은 하나(위 버튼, 지역 상품은 상점 안 목록). 도감·업적은 위 메뉴.
- 공통 규칙: 등급 색 체계 하나 · 반면교사 원칙(핵심 재미에 타이머 금지 등) · 톤 "시스템은 진지, 이야기는 웃기게" · 대표 수치 = **회사 레벨**.

## 2. 보이는 방식 (사용자 확정)
- **모든 기능이 제자리에 보인다.** 데모에 없는 탭·입구도 그 자리에 이름이 있다.
- **미구현 = 가로 취소선** (예: ~~대장간~~). 누르면 "준비 중" 한 줄.
- **잠김(플레이하면 열림) = 🔒 + 열림 조건** (예: 🔒 친위대 — 첫 납품 시). 두 가지를 섞지 않는다.

## 3. 첫 데모 (한 바퀴 = 10분)
| 시간 | 흐름 |
| --- | --- |
| 0~1분 | 의뢰 수락 → 추천 건설(의뢰 예산) → 기본 부대 출진 |
| 1~4분 | 첫 전투 → 카드 넘기기 → 부대 성장 확인(전투 뒤 경험치 책) |
| 4~7분 | 작은 **2층** 열림 → 층별 출진 → 강해진 적 방어 |
| 7~10분 | 납품(첫 납품 7~8분) → 회사 레벨·작품 등록·친위대 인계 → **두 번째 현장 첫 전투** |
- 범위: 고정 의뢰 1개(전투 3주 안팎) + 짧은 두 번째 의뢰, 시설 3종, 부족 2종, 고정 구역 1개, 카드 6~8장(주당 제한), 부족 강화 1회, 친위대 인계 1회, 작품집 기록 1 + 효과 1.
- 통과 기준: 설명 없이 다음 주를 진행할 수 있다 / 무엇이 강해졌는지 안다 / 다음 현장에서도 계속하고 싶다.
- 데모에서 열리는 탭: 회사·현장·군단. 마계·내 집은 제자리에 있되 취소선.

## 4. 우선순위
| 단계 | 내용 |
| --- | --- |
| ① 첫 데모 | 위 3번 |
| ② 출시 | 응접실(의뢰인 방문·평가·호감도) · 소장실(직급 칭호·재능) · 포로 수용소(몸값) · 보스 주(자동 리듬) · 소장 스킬 버튼 · 지역 2~3곳 + 포탈 · 모험가 길드(첩보·도감·단골) · 카드 도감 · 일일 점수제(핵심 플레이만으로 큰 보상, 광고·뽑기 필수 아님) · 방치 12시간·광고 즉시 받기 · 3층 |
| 출시 후보 (필수 아님) | 지점 · 저택·부대장 집·호감도 · 몬스터 숙소·사기 · 시즌 테마 부지(상시 의뢰 재사용이 된 뒤) |
| ③ 출시 후 | 직원실 · 대장간 · 라이벌·조합·랭킹 · 시장 확장(경매·암시장·떠돌이) · 행사장 · 주점·진열장 · 교역로 · 마계 뉴스 · 비동기 침공·협동 · 합성·희생 · 손해 시설·나쁜 방·시설 조합 |

## 5. 열림 순서 (기능은 필요한 경험 직후에, 회사 레벨은 보조 조건)
| 시점 | 열림 |
| --- | --- |
| 시작 | 현장 + 회사(의뢰 게시판). 1층. 현장에서 기본 부대 모집·출진 가능 |
| 첫 전투 뒤 | 군단 탭(부족 목록·보석 강화 1회·훈련) |
| 첫 의뢰 끝 무렵 | 작은 2층 |
| 첫 납품 | 친위대 지정 · 작품집 |
| 두 층에 익숙해진 뒤 | 3층 |
| 첫 포획 뒤 | 포로 수용소 / 같은 모험단 재등장 뒤: 모험가 길드 / 새 지역 의뢰 직전: 마계 지도 |
- 직급은 회사 레벨 구간의 이야기 칭호(연출), 기능 열림 조건은 경험 중심.

## 6. 규칙 정리 (충돌 정리 결과)
| 주제 | 확정 |
| --- | --- |
| 돈 | **회사 금 = 영구 해금·강화**, **의뢰 예산 = 이번 현장 건설·인원 조달**. 환불 없음. 예산이 바닥나도 무료 기본 부대로 진행 가능. 절약 보너스는 상한 있는 부가 보상 |
| 남는 것 | 부족 사용권 · 부족 보석 강화 · 친위대 · 회사 레벨 · 작품집. 현장 부대는 의뢰마다 조달, 납품 때 인계 |
| 출진 | 층별 출진(기본 자동·기본 퇴각 기준). 몬스터는 대기실 칸만 배회, 함정 칸은 함정만. 퇴각하면 다음 주까지 쉼. 층마다 출진 한도 |
| **부대 성장 (사용자 확정)** | 경험치는 **출진·참여 단위**(막타 계산 없음). **친위대도 층별 출진 칸을 차지** → 친위대를 많이 쓸수록 크는 부대가 줄어듦 |
| **경험치 책·훈련 교본 (사용자 확정)** | 전투가 끝나면 보상으로 받음 → **부대나 친위대를 골라** 레벨업. **친위대 레벨이 높을수록 부대 훈련 효율 상승**(친위대가 교관 역할) |
| 의뢰 목표 | 주목표 1 + 부목표 1 이내. 부대 레벨 목표 = 현장 부대 숙련도(친위대 레벨 미포함) **[바뀜 10-23 → GAME_PLAN 의뢰 목표·층·재화 절: 납품 기준 1~5단계 묶은 기준선, 5단계 모두 채워야 납품]** |
| 사망 | 부대 개별 인원만 사망 확률(큰 피해 때), 쌓은 숙련도는 안 줄어듦, 전멸하면 기본 인원 다음 주 무료 보충. **첫 의뢰는 사망 없음**. 친위대 불사(쓰러지면 퇴각) |
| 새 부족 | 레벨 공유 없음. 회사 레벨에 따른 기본 시작 레벨(의뢰 목표보다 낮게) |
| 몬스터 얻기 | 모집(금) + 전투 보상. 알은 보상 연출로만. 합성·희생은 출시 후 |
| 층 | 세로 지하 층, 층별 고정 이동 경로부터. 판 3종 → 층 안 구역 배치 몇 가지 |
| 카드 | 4방향, 짧은 문장·즉시 보이는 효과, 카드·이벤트 등급 연출. 주 시작 운명 카드는 없음(휴식·정예·보스 주는 자동) |
| 자동 | 자동 전술 기본 켬. 카드 자동 넘기기는 별도 설정(기본 꺼짐) |
| 성장 숫자 | 대표 = 회사 레벨. 전투력·부대 레벨·던전 가치는 각 화면의 수치로 |
| 서두르기 | 없음(건설 즉시) |
| 정산 | 납품 화면에 "인계되는 것 / 남는 것"을 실제 수치로, 다음 현장에서 남은 효과를 한 번 강조 |
