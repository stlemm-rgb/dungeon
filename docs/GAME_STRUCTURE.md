## 2. 하단 탭 5개 × 입구
| 탭 | 화면 | 입구 |
| --- | --- | --- |
| ① 사무소 (홈) | 하청 건설사 건물 단면 | 의뢰 게시판 · 소장실 · 비서실 · 응접실 · 직원실 |
| ② 현장 (가운데) | 세로 지하 단면 | 건설 · 출진 칸 · 포로 수용소 · 전투 · 납품 |
| ③ 군단 | 마계 병영 | 부족 막사 · 친위대 전당 · 훈련장 · 보석 제단 · 대장간 · 몬스터 숙소 |
| ④ 마계 | 마계 지도 | 지역(포탈) · 작품집 거리 · 지점 · 모험가 길드 · 라이벌 건설사 · 시장 · 행사장 |
| ⑤ 내 집 | 저택 + 부대장 마을 | 저택 · 부대장 집 · 식당·주점 · 진열장 |
- 탭 밖: 상점(위 버튼), 도감·업적(위 메뉴), 공통 규칙(등급 색 체계·반면교사 원칙·톤·숫자 목표).

## 3. 우선순위 (① 첫 데모 = 한 바퀴 / ② 출시 / ③ 출시 후 업데이트)
기준: 핵심 재미(성장·카드 넘기기·전투 보기)와 바로 이어지나 · 1인 개발 비용 · 반면교사 원칙.

| 단계 | 입구 (내용) |
| --- | --- |
| **① 첫 데모** | 사무소: 의뢰 게시판(고정 구역 미리보기) · 비서실(방치 보상·일일 점수제) / 현장: 건설(층·고정 구역, **의뢰 예산**) · 출진 칸 · 전투(4방향 카드·등급 연출) · 납품 / 군단: 부족 막사(모집·뽑기) · 친위대 전당 · 보석 제단 / 마계: 작품집 거리(목록·로열티만) |
| **② 출시** | 사무소: 응접실(의뢰인 방문·평가·호감도) · 소장실(직급·재능) / 현장: 포로 수용소(몸값) · 보스 주 · 소장 스킬 버튼 / 군단: 훈련장(레벨 공유) · 몬스터 숙소(회복·사기) / 마계: 지역 2~3곳 + 포탈 · 지점(숲 1곳) · 모험가 길드(첩보·도감·단골 근황) · 시장(지역 상점) / 내 집: 저택(가구 칸 3~5·꾸밈 점수) · 부대장 집(좋아하는 가구·부탁 3개) / 공통: 카드 도감 · 시즌 테마 부지(운영 핵심) · 방치 12시간·광고 즉시 받기 |
| **③ 출시 후** | 직원실·교육 · 대장간(장비·인챈트) · 라이벌 건설사·조합·랭킹 · 경매장·암시장·떠돌이 상인 · 행사장(건설 대회·탑/심연·축제) · 식당·주점 · 진열장 · 교역로 · 마계 뉴스 · 비동기 침공·협동 · 몬스터 합성·희생 · 손해 시설·나쁜 방·시설 조합 |

## 4. 열림 순서 (진행판의 장·직급과 연결)
| 시점 | 새로 열림 |
| --- | --- |
| 시작 | **② 현장** + **① 사무소**(의뢰 게시판·비서실). 1층만 |
| 첫 납품 (10분 안) | **③ 군단** 탭(부족 막사·친위대 전당·보석 제단) · **④ 마계** 탭(작품집 거리만) |
| 1장 중반 (공병장 합류) | 응접실 · **2층** · 층별 출진 한도 +1 |
| 대리 승진 (1장 끝) | 소장실(재능) · 훈련장 · 지점(숲) |
| 2장 (드래곤, 설원 포탈) | 모험가 길드 · 포로 수용소 · **⑤ 내 집** 탭(저택) · **3층** |
| 과장 승진 (2장 끝) | 부대장 집·호감도 · 시장 · 몬스터 숙소 |
| 3장 이후 | ③ 출시 후 입구를 업데이트로 하나씩 |
- 잠긴 입구는 **자물쇠 + 열림 조건 한 줄**로 보이게(기대감), 처음 열릴 때 짧은 연출.

## 5. 충돌 정리 (총괄 제안)
| # | 부딪히는 것 | 정리안 |
| --- | --- | --- |
| 1 | 지금 시안 "플레이어 금으로 건설·첫 공사비" vs **의뢰 예산**(사용자 확정) | 의뢰 예산으로 교체. 남은 예산 일부 = 납품 "절약 보너스". 건설 공방 "할인" → "같은 예산으로 더 짓기" |
| 2 | 지금 시안 "대기실마다 몬스터 배치" vs **출진**(확정) | 출진으로 교체. 대기실 = 몬스터가 배회하는 칸 |
| 3 | 건설 요구 6종 vs 고정 구역(확정) | 요구 삭제. 의뢰 목표 = 방어 횟수·**몬스터 부대 레벨**(확정)·가치 |
| 4 | 판 3종(평면) vs **세로 지하 층** | 층(1·2·3층) 구조로. 판 모양은 "층 안 구역 배치 몇 가지"로 줄임 (큰 변경) |
| 5 | 매주 카드 3장 중 1장(운명 카드) vs 전투 중 4방향 카드 | 층위가 다름: 4방향 카드 = 전투 중(데모), 운명 카드 = 주 시작 리듬(출시, 보스 주와 묶음) |
| 6 | 몬스터 얻는 길이 너무 많음(모집·뽑기·알·합성·희생) | 얻기 = 모집(금)·뽑기(광고·보석)·알(전투 보상). 키우기 = 의뢰 중 레벨 · 보석 강화(영구). 합성·희생은 출시 후 |
| 7 | 성장 숫자가 여러 개(명성·평판·회사 등급·직급·배율·대표 수치) | **대표 수치 하나 = 회사 등급(별)**. 직급은 이야기 칭호로 회사 등급에 묶음. 지역 평판은 출시 후 |
| 8 | 방치 수입이 여러 곳(방치 보상·로열티·지점) | 비서실에서 **한 번에 받기** |
| 9 | 일일·주간 퀘스트(지금) vs 점수제 | 점수제로(20점마다 보상, 100점 큰 보상) |
| 10 | 서두르기(Fallout Shelter) vs 반면교사(핵심 재미에 타이머 금지) | 건설이 즉시라 서두르기 불필요 → 빼기 |
| 11 | 자동 대응 기본값(재검토 중) | **켬** (생각 없이 보기) |
| 12 | 친위대 출진 vs 부대 성장(확정: 친위대 쓰면 부대 레벨 안 오름) | 친위대가 처치한 몫은 부대 경험치에서 뺌 / 친위대는 불사(쓰러지면 퇴각), 부대는 사망 확률(큰 피해 때만, 부족 보석 강화는 남음) |
