# Codex 의견: 현장 건설 모드 개선 + 회사 대시보드 (2026-10-23)

> 질문: B안(건설 모드) 다듬기. 새 탭 구조(마계·군단·회사(가운데)·현장·내 집, 가운데 = 홈/다음 주) 기준. 읽기 전용 하청, 총괄 검수. 레퍼런스 refs/ref_ui_layout_2026-10-23.md

**B안의 ‘빈 구역이 빛나는 건설 모드’를 유지하고, 조작부를 화면 아래 한곳에 모으는 안을 추천합니다.** 1인 개발이라면 건설과 출진을 분리하는 것부터 하세요. 조작이 단순해지고 화면 상태를 점검하기도 쉽습니다.

파일은 수정하지 않았습니다. 아래 평가는 HTML·문서·코드 기준입니다.

**1. B안의 문제점**

| 문제 | 사용자에게 생기는 불편 |
|---|---|
| 빈 구역과 시설 목록이 동시에 선택을 요구함 | 칸부터 누르는지, 시설부터 고르는지 모호함 |
| 안내·빈칸 테두리·닫기가 모두 강하게 강조됨 | 지금 눌러야 할 곳이 분명하지 않음 |
| 떠 있는 ‘닫기’가 현장 위에 겹침 | 구역을 가리고, 시설 선택과 종료 사이 손가락 이동이 생김 |
| 건설 중에도 ‘층을 누르면 출진’ | 구역을 고르다가 다른 작업으로 넘어갈 가능성 |
| 가격만 있고 확정 전 결과 비교가 없음 | 가치·전투력 효과를 모르고 환불 불가능한 건설을 결정함 |

기존 시안의 현장 ‘다음 주’와 탭 순서는 최신 결정대로 교체하면 됩니다.

**2. 개선 제안 — 우선순위 순**

근거의 ‘광산·쉘터’는 제공된 [레퍼런스 정리](/C:/project/Dunguen/refs/ref_ui_layout_2026-10-23.md)를 뜻합니다.

| 순위 | 무엇을 바꿀지 | 이유·근거 | 난이도 |
|---|---|---|---|
| 1 | 하단 작업 줄에 **[건설] 하나**. 켜면 같은 자리가 **[건설 끝내기]**로 바뀜. 나가면 미확정 선택 취소 | 진입·종료 위치를 기억하기 쉬움. 떠 있는 닫기 제거. **쉘터** | 하 |
| 2 | **구역 → 시설 → 미리보기 → 짓기** 순서 고정. 구역 선택 전에는 시설 목록을 숨김 | 구역 크기·층·종류에 맞는 시설과 실제 비용만 제시 가능. **쉘터**, 현재 데모 흐름 재사용 | 하 |
| 3 | 시설 선택창 아래에 **고정 미리보기**: 비용·잔액, 던전 전체 가치·전투력 전후. 층별 조건이 있으면 해당 층 변화 한 줄 추가 | 선택과 결과를 한곳에서 비교. 몬스터 대기실은 **기본 부대 +1**, 자동 편성 반영 여부도 표시 | 중 |
| 4 | 시설을 눌러도 돈은 쓰지 않음. **[마석 N 사용해 짓기]**로만 확정. 바로 위에 ‘건설 후 환불 없음’ | 확정 전 취소는 자유롭게. 기존 시설 교체 때는 사라질 시설·빠질 부대도 표시. 잘못 지은 뒤에는 환불 대신 **매주 마석 +30** 안내 | 하 |
| 5 | **출진은 별도 화면**. 평상시 하단 [출진] 하나로 진입하고 층별로 배치. 건설 중 층을 눌러도 출진하지 않음 | 기본 자동 편성으로 충분한 사람은 건설에 집중. 층에는 `출진 부대 1/3` 같은 정보만. **광산·쉘터** | 하 |
| 6 | 3층이 되어도 **단면만 세로 스크롤**, 작업 줄·탭은 고정. 층·구역을 작게 압축하지 않음 | 층이 늘어도 버튼 수 유지. 시설창을 열면 선택 구역이 창 위에 보이도록 이동. **공통 원칙** | 중 |
| 7 | 첫 안내는 **건설 버튼 → 큰길의 추천 빈 구역 한 곳 → 몬스터 대기실 → 확정 버튼**만 차례로 반짝임 | 한 번에 행동 하나만 가르침. 다른 건설 가능 구역은 얇은 테두리만. 고정 하역장·곁방까지 함께 강조하지 않음 | 중 |
| 8 | 상단은 **현장명·주·마석 + 납품 기준 요약** 두 줄. 구역 상세·통과 인원·계산식은 선택창에서만 표시 | 단면을 위한 공간 확보. 갈림길 의뢰부터 선택 구역의 통과 인원 전후를 보여 주면 배치 이유를 이해하기 쉬움. **광산** | 하 |

‘전투력’에는 **납품 기준용**이라는 설명을 붙이는 편이 좋습니다. 현재 코드에서는 쉬는 부대도 포함하므로, 이번 주 실제 출전 상태는 출진 정보로 따로 보여 주세요.

**3. 최종 배치 한 개 — 두 상태**

아래는 3층 의뢰 기준입니다. 첫 의뢰에서는 1층만 보여 주고, 해당 의뢰에서 열릴 층만 잠금 조건을 표시합니다.

**건설 모드 꺼짐**

```text
+----------------------------------+
| 현장명 · 1주째        마석 N      |
| 납품 기준 n/5 · 가치 N/N · 전투력 N/N |
+----------------------------------+
| 지상 · 현장 입구                  |
|                                  |
| 지하 1층 · 출진 부대 1/3          |
| [함정] [몬스터 대기실] [빈 구역]  |
|            ↓ 계단                |
| 지하 2층 · 출진 부대 1/2          |
| [구역] [구역] [구역]              |
|            ↓ 계단                |
| 지하 3층 · 구역 / 잠금 조건       |
|          ↕ 단면만 스크롤          |
+----------------------------------+
| [출진 · 자동 편성 켬]    [건설]    |
| 포로 수용소 · 작은 보조 입구       |
+----------------------------------+
| 마계 | 군단 | 홈 | 현장 | 내 집   |
+----------------------------------+
```

**건설 모드 켜짐 — 구역·시설 선택 후**

```text
+----------------------------------+
| 현장명 · 1주째        마석 N      |
| 납품 기준 n/5 · 가치 N/N · 전투력 N/N |
+----------------------------------+
| 지상                             |
| 지하 1층                         |
| [기존 시설] [+ 빈 구역] [선택 칸] |
| 지하 2층 …                       |
| 지하 3층 …      ↕ 세로 스크롤    |
+----------------------------------+
| 건설 · 지하 1층 / 선택한 구역     |
| [함정]       [몬스터 대기실]      |
| ※ 선택 구역에 가능한 시설만      |
|----------------------------------|
| 비용 N · 마석 N → N              |
| 가치 N → N · 전투력 N → N        |
| 基本 부대 +1 / 자동 편성 결과     |
| 건설 후 환불 없음                |
| [선택 취소] [마석 N 사용해 짓기]  |
+----------------------------------+
|                   [건설 끝내기]  |
+----------------------------------+
| 마계 | 군단 | 홈 | 현장 | 내 집   |
+----------------------------------+
```

시설창은 **구역을 고른 뒤에만** 열립니다. 건설을 마치면 창과 선택을 지우고 건설 모드는 유지합니다. 탭 이동 시에는 미확정 선택을 취소합니다.

가운데는 현장에서 **홈**, 회사에서는 **다음 주**입니다. 현장에 전투 시작 버튼을 추가하지 않습니다.

**4. 회사 대시보드**

| 꼭 있어야 할 것 — 최대 5개 | 빼야 할 것 — 최대 5개 |
|---|---|
| 의뢰명·납품 기준 n/5·다음 기준 대비 가치·전투력. 완료 시 납품 입구 | 시설 목록·건설 가격표 |
| 현재 마석·매주 보급 +30·현장 바로가기 | 층마다 반복되는 건설·출진 버튼 |
| 이번 주 침입자 수·위험 특징·보스 예고 | 층별 구역 지도 전체 |
| 출진 준비 요약: 자동 편성 상태·쉬는 부대·출전 부대 없음 알림 | 개별 부대 능력치·장비 상세 |
| 회사 레벨·회사 금·신석을 묶은 작은 상태 줄 | 상세 계산식·길별 통과 인원 |

회사 화면의 가운데 **[다음 주]** 가까이에 ‘전투 진행 · 마석 보급 +30’을 짧게 붙이면, 누를 때 일어날 일을 예측하기 쉽습니다.
