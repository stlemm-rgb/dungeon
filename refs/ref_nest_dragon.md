# 참고: 둥지짓는 드래곤 — 둥지 짓기 방식 (요약)

출처: 사용자 제공 PDF 2개 (네이버 블로그 ujoa80, 2006 공략 "둥지 짓기 上·下"). 원본 PDF는 저장소에 올리지 않음.

## 구조
- **고정 지도**: 숲(야외) → 입구 → 입구 위·아래 → 중앙(좌·우 2곳) → 중앙 위·아래 → 안쪽 위·아래 → 용의 둥지 → 보물창고. 지을 수 있는 구역 11곳.
- **구역 하나 = 시설 하나**: 구역을 고르고 목록에서 시설을 고름. 유저가 길을 그리지 않음.
- **시설 = 미리 짜인 작은 미로**: 각 시설에 길 모양, 대기실(부하 칸 수), 함정 수, 기타, 가격이 정해져 있음. 빈 상태는 "동굴"(0원), "정리된 동굴"(1원).

## 유도는 시설 종류로
| 시설 (입구) | 효과 |
| --- | --- |
| 분기 | 대기실 2. 앞 통로가 위·아래로 이어져 일부 적은 그냥 지나감. 쌈 |
| 대기 | 대기실 2. 빠질 길이 없어 100% 통과. 강한 부하면 혼자 다 잡음, 약하면 위험 |
| 2개의 대기 | 대기실 2×2. 100% 요격, 적을 반씩 나눔 |
| 첫 번째 바위·화살·보물 | 100% 지나는 함정 (초반 체력 깎기) |
| 굽은길 1·2 | 적을 100% 아래 / 위로 보냄 → 그쪽에 강한 시설을 두고 몰아넣기 |
| 안내소 | 적이 헤매지 않고 깊이 들어옴 (역효과) |
| 미끼 | 가짜 보물창고. 들어온 적은 보물 조금 들고 100% 돌아감 |
| 돌려보내기 | 적 일부를 돌려보냄 (비쌈) |

## 구역마다 역할
- **입구**: 모든 적이 먼저 지남 → 기선제압.
- **입구 위·아래 / 중앙 위·아래**: 갈래로 일부 적만 옴 → 보조 요격, 잔당 처리, 돈 버는 시설.
- **중앙**: 넓어서 큰 대기실(최대 21명), 큰 함정(함정지옥 18) 가능.
- **안쪽**: 지원시설(전투지휘소, 휴게실, 치료실) 또는 감옥(포로).
- **용의 둥지**: 마지막 관문, 앞에 대기실.

## 손해가 있는 선택과 해금
- 상점: 돈을 벌지만 지나간 적이 강해짐. 여관: 돈을 벌지만 적 체력 회복.
- 시설 해금: "누적 재력 N 이상 쓴 뒤 현재 재력 M 이상" 같은 조건.
- 시설 조합형: 화살공격(함정 방 2개 → 대기실 4), 고객의 비극(상점 + 대기실) 등.

## 우리 게임에 가져올 점 (총괄 정리)
1. 침입자 "유도"를 그리기가 아니라 **시설 고르기**로 (분기/대기/굽은길/미끼).
2. **구역 역할**이 "어디에 무엇을" 퍼즐을 만든다 → 방 순서가 결과를 바꾸는 조건이 자연스럽게 생김.
3. 시설에 함정 수·몬스터 칸이 묶여 있어 **마왕 요구(함정 비율·가치)** 퍼즐과 바로 연결.
4. 해금·손해 시설·미끼는 기획의 회차 이득·미끼 아이디어와 맞음.
