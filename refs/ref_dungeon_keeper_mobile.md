# 반면교사: Dungeon Keeper 모바일 (EA, 2014) (2026-10-22)

> 조사 방식: ① 웹 검색(위키백과·리뷰·EA 경영진 발언·영국 광고 심의). ego 안 씀.
> 출처: 위키백과 "Dungeon Keeper (2014 video game)", 영국 광고표준위원회(ASA) 판정 페이지, Escapist·Gamereactor 리뷰, MCV(EA CEO 발언), Ultima Codex(EA Mobile 대표 발언), Melior Games 실패 사례, BBC 인용(몰리뉴 발언, 2차 보도).

## 무엇
- 명작 PC 던전 경영 「던전 키퍼」(피터 몰리뉴)의 이름을 빌린 **무료 + 인앱 결제** 모바일판. Mythic Entertainment 개발, EA 배급, 2014년 iOS·안드로이드. **2022년 8월 서비스 종료**.

## 무엇이 잘못됐나
| 문제 | 내용 |
| --- | --- |
| **기다림으로 재미를 막음** | 땅파기·건설·훈련이 실제 시간 타이머. 블록 하나 파는 데 몇 시간~하루, 보석(유료)으로만 빨리 → "재미를 일부러 느리게 해서 결제를 늘렸다" |
| 원작자도 분노 | 몰리뉴: "블록 하나 파러 6일 동안 알람 맞춰 돌아오고 싶지 않다" |
| **평점 조작** | 안드로이드에서 별점 창의 "5점"을 누르면 스토어로, "1~4점"은 EA에게 의견만 보내게 함 → 나쁜 평가가 스토어에 안 올라가게 |
| 광고 문제 | 영국 광고표준위원회: 광고가 **소비자를 오도**했다고 판정 → 광고 수정 (EA는 "무료이고 결제는 필수 아님"이라고 반론) |
| 이름값 배신 | 원작 팬의 기대와 정반대 → 팬이 가장 크게 반발 |

## 회사의 사후 인정
- EA CEO 앤드루 윌슨: "**경제를 잘못 판단했다.**" 옛 작품을 되살릴 땐 그 본질에 충실해야 함. 어떤 사업 모델이든 **가치를 줘야 함**.
- EA 모바일 대표: 마케팅·팬 소통 부족, "너무 많이 새로 시도했다" → 비평가들은 "돈을 강제로 쓰게 만드는 걸 싫어할 뿐"이라고 반박.

## 우리가 피할 것 (체크리스트)
| 하지 말 것 | 대신 |
| --- | --- |
| 핵심 재미(건설·전투·카드)에 **실제 시간 타이머** | 기다림은 방치 보상·지점 같은 **부가** 쪽에만. 건설은 즉시(지금 시안 그대로) |
| 결제해야만 정상 속도 | 결제·광고는 **조금 빠르게**일 뿐, 안 써도 같은 재미 (DM처럼 "플레이로 다 열림" 명시) |
| 별점 거르기(5점만 스토어로) | 스토어 공식 평가 창만 사용. 화난 사람도 그대로 평가하게 (지금 스토어 정책도 평가 거르기를 금지하는 쪽, 총괄 지식) |
| 광고에 없는 경험을 약속 | 스토어 문구·스크린샷은 실제 플레이 화면 그대로 |
| 유명작 흉내로 기대만 높임 | 우리만의 컨셉(마계 하청 건설사·지어서 팔기)으로 |
| 출시 뒤 팬과 대화 없음 | DM처럼 출시 직후 잦은 업데이트 + 공략 커뮤니티 |
