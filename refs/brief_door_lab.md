# 지시서: 문 토큰 최소 실험 페이지 (Codex 하청, 2026-10-23)

설계 근거: `docs/DESIGN_DOORS.md` 8~10절 (반드시 읽기). 핵심 재미 확인용 **별도 실험 페이지**. 기존 게임 코드와 저장은 건드리지 않는다.

## 고칠 파일 (이 폴더만 새로 만든다)
`prototype/door_lab/index.html`, `prototype/door_lab/lab.js`, `prototype/door_lab/lab.css`, `prototype/door_lab/selftest.js`. **다른 파일은 하나도 고치지 않는다.** 커밋하지 않는다.

## 만들 것
순수 JS(라이브러리 없음), 한국어 화면, 휴대폰 세로 390px 기준(넓은 화면에서는 가운데 정렬). 색은 lab.css 맨 위 CSS 변수로만. `confirm`/`alert` 금지. 무작위가 필요하면 시드 고정 난수(같은 배치 = 같은 결과).

### 1. 판
- 가로 3 × 세로 4 = 12칸, **1칸 = 1방**. 좌표 (행, 열), 행 0이 위.
- 입구 = (0,1), 보물방 = (3,1). 바깥 벽에는 문 없음. 침입자는 판 위쪽 밖에서 입구로 들어온다.
- 안쪽 벽 조각 = 이웃 칸 사이 17개(가로 이웃 8 + 세로 이웃 9). 그중 **문 12개**. 처음 배치는 연결된 유효한 배치로 하나 정해 둔다.
- 시설 고정: 함정 2개 (1,0)·(2,2) / 몬스터 대기실 1개 (2,0) (몬스터 3마리) / 미끼 1개 (1,2). 표시만, 옮길 수 없음.

### 2. 문 토큰 조작
- 문(벽 위 표시)을 끌어서 **문이 없는 다른 안쪽 벽 조각**에 놓는다. 놓는 순간 옛 자리 닫힘·새 자리 열림을 한 번에 판정. 끄는 동안 놓을 수 있는 벽 조각을 밝게, 손가락(터치) 위 64px에 끄는 그림을 띄운다. 마우스는 0px. 포인터 이벤트로 터치·마우스 모두.
- 끄는 동안 **경로 미리보기가 실시간으로** 바뀐다(놓기 전 후보 자리 기준).
- 규칙 위반이면 놓지 않고 제자리 + 이유 한 줄: ① 입구 → 보물방 연결 끊김 ② 어떤 분대든 왕복 포함 문 통과가 18회 초과.
- 고립된 방은 허용. 고립된 방의 시설은 흐리게 표시하고 전투에서 효과 없음.
- [되돌리기](한 단계씩), [처음 배치]. [경로 숨기기] 토글(사용자가 먼저 예측해 보고 보기용).

### 3. 탐험 이동 규칙 (경로 미리보기와 실제 전투가 **같은 함수**를 쓴다)
- 분대 3개(분대 1·2·3, 각 10명). 분대마다 **자기가 가 본 방** 기록(분대끼리 공유 안 함).
- 지금 방에서 문으로 이어진 이웃 중 **안 가 본 방**이 후보. 후보가 여럿이면: 미끼가 있는 방이 우선 → 같으면 화면 기준 **왼쪽·위·오른쪽·아래** 순서.
- 우선순위가 완전히 같은 후보끼리만 분대 번호로 번갈아: 같은 후보가 n개면 분대 k는 (k-1) mod n 번째부터 먼저 가고, 나머지는 위 순서대로 나중에.
- 안 가 본 이웃이 없으면 **들어왔던 방으로 되돌아가** 거기서 다시 확인(깊이 우선 + 되짚기).
- 보물방에 처음 들어가면 그 분대 이동 끝.
- 결과 = 분대별 방 목록(되돌아가는 칸 포함). 이 목록으로 미리보기 선과 실제 이동을 둘 다 만든다.

### 4. 경로 미리보기
- 판 위 SVG에 분대별 선(색 3개, 겹치지 않게 조금씩 비켜서), 방 중심 → 문 → 방 중심. 진행 방향 화살표. 되돌아가는 구간은 점선.
- 문 위에 그 문을 지나는 총 횟수(세 분대 합) 작은 숫자.
- 분대별 문 통과 수 표시(최대 18).

### 5. 실시간 전투 (간단해도 됨, 60초 제한, [전투] 버튼)
- 분대는 경로 목록을 따라 움직인다. 기본 속도는 방 하나 지나는 데 약 2초.
- **이동 속도 1.5배**: 그 분대가 **이미 가 본 방**으로 다시 들어갈 때, 그리고 **빈 몬스터 대기실**(몬스터가 없거나 다 쓰러짐)에 있을 때. 이 기록은 전투 중에만 쓰고 저장하지 않는다.
- 함정: 방에 들어갈 때 분대 인원에게 피해. **같은 함정은 같은 분대에 최대 2회**.
- 대기실: 몬스터가 살아 있으면 그 방에 들어온 분대와 싸운다(분대는 싸우는 동안 멈춤). 단순 체력·공격력 숫자로.
- 미끼: 경로 선택에만 영향.
- 60초가 지나면 끝. 결과: 보물방 도달 인원, 쓰러뜨린 인원, 함정 발동 수, 분대별 문 통과 수, 걸린 시간. **시간 초과는 방어 성공으로 치지 않는다**(도달 못 한 인원은 "시간 초과"로 따로 표시).
- **직전 결과와 지금 결과를 나란히** 표로(같은 침입자·같은 시드).

### 6. 측정 기록 (화면 아래 작은 패널, 접기 가능)
편집 횟수, 거절된 놓기 횟수, 편집에 쓴 시간, 전투 횟수. 저장은 하지 않아도 됨(새로고침하면 초기화).

### 7. selftest.js
`node prototype/door_lab/selftest.js`로 실행. lab.js의 순수 계산 함수(연결 검사, 탐험 경로, 문 통과 수)를 불러 확인: 처음 배치가 유효, 연결 끊는 이동 거절, 18회 초과 거절, 막다른 방에 들어갔다 되돌아 나오는 경로, 미끼 우선, 동점 분대 번갈아, 같은 입력 = 같은 경로. lab.js는 브라우저와 node 둘 다에서 읽히게(예: `if (typeof module !== 'undefined') module.exports = …`).
