# Codex 의견: 현장 돈 이름 (2026-10-23)

> 질문: '의뢰 예산·주간 지원금'이 회사 금과 헷갈림 → 권리증(건설권·고용권)·어음 등 건설 용어로 바꾸면? 읽기 전용 하청 결과, 총괄 검수.

**추천은 ‘현장 예산’ + ‘주간 예산 보충’입니다.** 회사 금과 현장 돈의 차이가 이름에 드러나고, 보충금이 같은 잔액에 들어간다는 점도 설명하기 쉽습니다. 1인 개발에서는 재화를 나누기보다 이 표시로 먼저 이해도를 확인하는 편을 추천합니다.

**1. 후보 비교** — 이해도·헷갈림은 UX 관점의 예상입니다.

| 후보 | 헷갈림 / 첫 이해 | 세계관 맛 | 화면 표시 영향 | 규칙·밸런스 영향 |
|---|---|---|---|---|
| **(a) 의뢰 예산 + 주간 지원금** | 보통 / 쉬움. ‘지원금’을 별도 재화로 오해할 수 있음 | 의뢰인이 비용을 대는 구조에 잘 맞음 | 지원금에도 **예산과 같은 아이콘** 사용 | 현재 규칙 유지. 반복 지급으로 회복 가능 |
| **(b) 건설권·고용권** | 회사 금과 혼동 낮음 / 사용처는 명확. 다만 ‘권 1장=건물·부대 1개’로 예상하기 쉬움 | 계약·관료제 분위기 | 회사 금까지 **잔액 3개**, 아이콘 3종 필요 | 한쪽 과소비가 다른 쪽에 영향 주지 않음. 대신 지급량·가격·보충을 각각 설계 |
| **(c) 공사비 + 주간 공사비 지급** | 보통 / 익숙함. ‘보유액’보다 ‘건설 비용’으로 읽힐 수 있음 | 건설사 느낌 강함 | 지폐·장부에 공사 표식 필요 | 규칙 유지. 부대 조달에도 쓴다는 안내 필요 |
| **(d) 현장 예산 + 주간 예산 보충** | **낮음 / 쉬움.** 회사↔현장 구분과 잔액 증가가 직접 드러남 | 현재 ‘현장’ 탭과 자연스럽게 연결 | 청록 장부 하나로 잔액·보충·비용 통일 | **현재 규칙 그대로** |
| **(d) 현장 지급권 + 주간 지급권 지급** | 낮음 / 보통. 돈 대신 전용 이용권으로 이해 | 마계 의뢰인의 인장으로 개성 부여 가능 | 인장 찍힌 증서, 단위는 ‘장’ | 하나로 유지하면 규칙 동일. 유료 티켓처럼 보일 가능성 |

문서 8절에서 **구분 없는 ‘공사비’**를 피한 방향은 타당합니다. 교체한다면 작업 화면 이름과 맞는 ‘현장 예산’이 가장 자연스럽습니다.

**2. 실제 건설업 용어의 적합성**

| 용어 | 게임에 맞는 자리 | 판단·이유 |
|---|---|---|
| **공사비** | 건설 비용, 의뢰 상세의 비용 설명 | 익숙하지만 잔액 이름으로는 다소 모호함 |
| **선급금·선금** | 의뢰 수락 때 받는 최초 260 | **최초 지급의 이름으로 적합.** 매주 받는 돈이나 전체 잔액 이름에는 어색함 |
| **기성금** | 완성한 공사 부분에 따라 받는 돈 | **현재 +10에는 부적합.** 건설 진전 없이 전투만 끝내도 받으므로 의미가 어긋남 |
| **도급** | 계약 방식·계약서 문구 | 돈 이름이 아님. 이야기와 의뢰 설명에 적합 |
| **어음** | 지급 지연·대금 회수 관련 사건 | 핵심 재화에는 비추천. 만기·현금화 설명을 기대하게 만듦 |

선금은 미리 지급하는 대금, 기성대가는 완료된 부분에 대한 지급이라는 구분입니다. [생활법령정보 공사대가 안내](https://easylaw.go.kr/CSP/CnpClsMainBtr.laf?ccfNo=5&cciNo=3&cnpClsNo=1&csmSeq=519&menuType=cnpcls)

어음은 금액 지급을 약속하거나 위탁하는 증서입니다. [한국은행 지급결제제도 자료](https://www.kif.re.kr/KMFileDir/129070405883763750_BOK%20%EC%9A%B0%EB%A6%AC%EB%82%98%EB%9D%BC%EC%9D%98%20%EC%A7%80%EA%B8%89%EA%B2%B0%EC%A0%9C%EC%A0%9C%EB%8F%84%282009%29.pdf) **제 판단으로는 ‘빚·외상·부도’ 인상이 하청회사 풍자에는 잘 맞습니다.** 다만 플레이어가 지금 쓰는 재화에 붙이면 지급 불안까지 규칙으로 예상할 수 있습니다. “마왕님이 현금 대신 어음을 보냈다” 같은 사건 대사에 더 어울립니다.

**3. 권리증 분리가 막힘을 없애는가?**

**‘부대에 돈을 다 써서 건설을 못 함’이라는 원인은 없앱니다. 모든 진행 막힘까지 없애지는 못합니다.**

| 바뀌는 점 | 남거나 새로 생기는 문제 |
|---|---|
| 고용권으로 건설권을 소비할 수 없음 | 잘못 지은 시설·환불 없는 철거로 건설권이 바닥날 수 있음 |
| 건설용 자원을 따로 보장 | 목표 가치에 충분한 양을 보장하거나 반복 보충해야 함 |
| 부대용 자원도 별도 보장 | 고용권 부족으로 전투력 기준이 막힐 수 있음 |
| 사용처가 명확해짐 | 한쪽은 남고 다른 쪽은 부족해도 돌려 쓸 수 없음 |
| 배분 실수를 제한 | **건설과 전투력 중 어디에 투자할지 고르는 경영 선택도 줄어듦** |

현재 +10 방식은 **예산 0에서도 전투를 계속 끝낼 수 있고, 승패와 무관하게 지급된다면** 회복 경로가 됩니다. 다만 부족한 건설비가 50이면 5전을 기다려야 하므로, 막힘 해소와 기다림의 재미는 별도로 확인해야 합니다.

**4. 최종 추천**

| 항목 | 추천 |
|---|---|
| 현장 재화 이름·단위 | **현장 예산**, 별도 단위 없이 `현장 예산 260` |
| 주간 지원금 이름 | **주간 예산 보충** — 최초 안내에 ‘의뢰인이 전투 종료마다 +10 지급’ |
| 회사 금 | **금색 동전**, `회사 금` 이름 유지 |
| 현장 예산 | **청록색 장부 + 의뢰인 인장**. 지급·소비에도 같은 아이콘 사용 |
| 최초 안내 | “건설·부대 조달에 사용합니다. 남은 예산은 납품하면 사라집니다.” |

화면 문구 예시 3줄:

> **진행표:** 현장 예산 260 · 납품 시 소멸  
> **전투 결과표:** 주간 예산 보충 +10 → 현장 예산 270  
> **건설 버튼:** 건설 · 현장 예산 30
