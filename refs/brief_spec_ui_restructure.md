## 확정된 것 (바꾸지 말고 구체화)
- 하단 탭 3개: **회사 · 현장 · 군단**. 데모에서 못 여는 탭은 숨김. [다음 주] 같은 행동 버튼은 탭이 아님.
- 현장 = 메인. 같은 판 4상태: **운영(일반 자동 반복) · 건설(판 크게) · 보스 도전 · 보스 결과**. 위아래 비율은 상태마다 다름.
- [보스 도전]은 현장 안 큰 버튼(DS [보스 도전] 자리). 단계 막대 = 보스 검증 n/5 (DS 스테이지 6-4 막대처럼). 마지막 보스 성공 → [납품].
- 보유·영구 성장 = 군단, 공간 편성(어느 대기실) = 현장. 군단엔 출진 위치 요약만.
- 성장 창 공통 표시 규칙: 대상 → 지금/다음 효과 → 비용 버튼 하나, **"이번 현장만 / 계속 유지"** 표시. 건설·출진·카드까지 한 틀로 묶지는 않음.
- DS에서 가져올 틀: 상단 바(전투력·재화·**다음 목표 한 줄**), 탭 안 하위 탭, 잠김 + 해금 조건 글.
- 안 함: 보유효과, 카드 수집·뽑기, 상점, 마계 지도, React 전환, 방치 보상.

## 기획서에 넣을 것
1. 왜 (3줄)
2. 화면 전체 틀: 상단 바 / 본문 / 하단 탭 — 무엇이 늘 보이고 무엇이 화면마다 바뀌나
3. **현장 4상태 표**: 상태 | 판(위)에서 보일 것 | 아래 판에서 할 일 | 들어오고 나가는 버튼. 그리고 **390px 세로 화면 글자 그림(ASCII) 4장**
4. 회사 탭: 의뢰 수락·납품·인물. 의뢰가 없을 때/있을 때 첫 화면
5. 군단 탭: 하위 탭(예: 부족·친위대·부대장) 구성, 목록·상세 모양(DS 동료 탭 참고), 출진 위치 요약
6. **기능 옮기기 표**: 지금 기능(현재 5탭 화면의 버튼·창 전부: 회사 홈, 출진, 건설, 강화 창, 전투, 결과표, 튜토리얼 말풍선, 데모 끝 등) | 새 자리 | 빠짐/합침 여부. 같은 기능 입구가 두 곳이거나 빠진 것이 없게
7. 상단 바·단계 막대·다음 목표 한 줄의 문구 규칙(예시 3개)
8. 데모 범위 / 안 할 것
9. 끝 기준: 첫 의뢰를 새 동선으로 끝까지, 390px에서 판·버튼 안 가림, 가로 넘침 0, check_all 통과
10. 사용자가 정할 것: 3~6개, 표 `질문 | 선택지 A/B/C(한 줄 장단점) | 아스트라 추천과 이유`
