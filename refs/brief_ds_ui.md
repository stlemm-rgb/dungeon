## 화면 구조 (시안 그대로)
1. **홈(시안 ①)** = 앱을 켜면 이 화면. 일반 침입 자동 반복이 늘 돌아감.
   - 위에서 아래로: 상단 바(소장 초상 + 회사 Lv 배지 · 전투력 · 회사 경험치 막대 · 마석 · 금) → 스테이지 막대(의뢰 단계 "1-n" · 일반 판 점 · 보스 표시 · 지난 시간 · [보스 도전]) → 전투장(판 가운데, 왼쪽 아이콘 의뢰·작품집·랭킹 / 오른쪽 임무·출석·설정, 오른쪽 아래 "다음 목표 + 보상" 상자) → 카드 6칸 → 시설 성장판(함정·대기실·미끼·문 칸 + 부대 모집 더미) → 하단 탭 6개 **회사·카드·군단·도전·마계·상점**.
   - 판의 칸 이름표("왼쪽 끝 1" 등)는 없앤다. 입구·고정 구역·대기실·보물방 같은 특별한 방과 지은 시설만 표시.
   - 배속·일시정지는 판 모서리 작은 버튼.
2. **보스 도전(시안 ②)**: 스테이지 막대가 빨간 보스 막대(이름 · 남은 분대)로 바뀜. 카드 기회가 오면(`S.pick`) 카드 6칸 중 후보만 밝아지고, 판 아래 겹친 작은 상자에 고른 카드 설명과 [사용], 막대 옆에 "카드 n/2 · 이유"와 [넘기기]. 방을 고르는 카드는 지금처럼 판에서 방 고르기 → [사용]/[취소]. 시설 성장판은 "보스전 중 잠김" 한 줄, 하단 탭은 흐리게 막힘.
3. **보스 결과**: 홈 위에 아래에서 올라오는 창(위쪽 판은 보임). 결론 한 줄, 분대별 한 줄씩(누르면 펼침), 카드 기록, [배치 고치기][다시 도전], 작은 글 "일반 침입 재개". 5/5 성공이면 [납품].
4. **탭 패널(시안 ③④)**: 탭을 누르면 홈 위로 아래에서 패널이 올라오고, **위쪽 약 150px에 전투가 계속 보임**(일반전은 계속 돈다 — 지금의 "현장 밖이면 멈춤" 규칙 대신, 로직 함수 그대로 쓸 수 있으면). 누른 탭 자리는 [닫기]로 바뀜.
   - **군단(③)**: 하위 탭 부족 · 친위대 · 부대장(잠김). 출진 칸(층 출진 한도만큼 칸, 나머지 잠김) · 총 보유 효과(잠김 칸) · 걸러 보기 줄(잠김) · 부족 격자(Lv·막대·강화 가능 표시) · [자동 편성](지금 자동 편성) [일괄 강화](잠김).
   - **회사(④)**: 하위 탭 회사 운영(잠김) · 직원(지금 사무실 무대·인물 대사 그대로) · 연구(잠김).
   - **카드**: 카드 3종 목록(설명만) + 잠긴 칸. **도전 · 마계 · 상점**: 누르면 패널에 "잠김" 한 줄.
5. **기존 기능 자리**
   - 건설: 시설 성장판 칸을 누르면 건설 모드(판 크게 + 그 시설 골라진 상태, 지금 build.js 조작 그대로) · 문 칸 = 문 옮기기.
   - 시설 강화: 지은 시설을 판에서 누르기(지금 그대로).
   - 출진·조달·보충: 부대 모집 더미 → 출진 창.
   - 의뢰 게시판·계약·납품 정산·데모 끝: 왼쪽 [의뢰] 아이콘에서 열리는 패널/창. 작품집 = 왼쪽 [작품집].
   - 설정: 오른쪽 아이콘.
   - 의뢰가 없을 때(첫 시작): 홈 판 자리에 의뢰 고르기 안내 → 수락하면 홈.

## 잠긴 칸 규칙 (사용자 결정)
- 기능 없는 칸·탭·아이콘·하위 탭은 **디자인 없이** 회색 상자 + 이름 + 자물쇠만. 누르면 토스트 "준비 중" (열림 조건이 실제로 있으면 그 조건).
- 대상: 랭킹·임무·출석 아이콘 · 카드 칸 4~6 · 도전·마계·상점 탭 · 부대장 · 총 보유 효과 · 걸러 보기 · 일괄 강화 · 회사 운영 · 연구. 빠뜨린 DS 칸이 있으면 같은 방식으로 넣고 보고.
