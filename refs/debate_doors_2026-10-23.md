# 토론: 문 2개 조건을 없앨 때 문 옮기기 방식 + 탐험 이동 규칙 (2026-10-23)

> 총괄 제안(막다른 방 = 재미, P1 문 토큰·P2 방 소유 문·P3 벽 놓기·P4 방 타일 회전, 탐험 세부) → Codex 반박. 합친 결론은 docs/DESIGN_DOORS.md 9절.

## Codex 답

**추천은 P1 ‘문 토큰’입니다.** 최소 문 수를 없애면 조작 제약이 줄어듭니다. 다만 **막다른 방의 재미는 왕복 자체보다, 어느 방을 먼저 탐험하게 만드느냐**에서 찾아야 합니다.

**1. ‘막다른 방 = 재미’에 대한 반박**

| 총괄 주장·위험 | 반박 / 보완 |
|---|---|
| 끝방에서 함정을 두 번 밟는다 | **자동으로 성립하지 않습니다.** 방 진입 시 발동이면 `A→끝방→A`에서 끝방 함정은 1회, A 함정은 재발동합니다. 두 번 통과하는 문턱 함정은 별도 설계입니다. |
| 막다른 방이면 유용하다 | 보물방을 먼저 발견하면 그 곁방에는 안 갑니다. **탐험 순서까지 유도해야** 유용합니다. |
| 왕복 피해가 재미를 만든다 | 길목의 강한 함정 하나를 반복해서 밟히는 배치가 정답이 될 수 있습니다. 함정별 재발동 한도를 먼저 정해야 합니다. |
| 무한 배회 | ‘안 가 본 **문**’보다 ‘안 가 본 **방**’을 기준으로 선택하고, 막히면 들어온 길을 되짚습니다. |
| 너무 긴 이동·1분 제한 | 왕복을 포함한 실제 이동량을 제한해야 합니다. **최단 거리 상한으로는 못 막습니다.** 시간 초과를 방어 승리로 처리하면 지연 미로가 정답이 됩니다. |
| 경로 예측 어려움 | 분대별 방문 기록과 고정 선택 순서를 사용합니다. 왕복선은 화살표·통과 횟수로 구분합니다. |

**2. 문 옮기기 방식 비교**

아래 평가는 현재의 작은 판·세로 화면·탐험 이동을 기준으로 한 예상입니다.

| 안 | 퍼즐 깊이 | 설명 없는 직관 | 끌어 놓기 손맛 | 구현 부담 | 밸런스 위험 |
|---|---|---|---|---|---|
| **P1 문 토큰** | 높음. 연결과 방문 순서 편집 | 높음. 문 뺀 곳은 닫히고 놓은 곳은 열림 | **높음** | 중간 | 시설 고립, 긴 미로, 강한 길목 집중 |
| P2 방 소유 문 | 중간. 국소적인 변경 | 낮음. 공유 문이 어느 방 소유인지 모호 | 중간. 이동 범위에 자주 걸림 | 중간. 소유 표시·선택 필요 | 소유 제한 때문에 유효한 이동이 부족할 수 있음 |
| P3 벽 토큰 | 높음. 통로를 좁히는 퍼즐 | 높음 | 높음 | 중간 | 넓게 열린 판에서 경로가 복잡하고, 벽 여러 개를 놓아야 효과가 보임 |
| P4 방 회전 | 중간~높음. 연결 조합 중심 | 중간. 양쪽 문 정합 규칙 필요 | 낮음. 누르기 중심 | 중간 | 회전할 때 주변 연결이 함께 끊겨 금지 조작이 많아질 수 있음 |

**P1은 문 하나를 옮기는 행동과 경로 변화의 관계가 가장 직접적입니다.** 기존 위치를 닫고 새 위치를 여는 과정을 한 번의 놓기로 판정하고, 연결이 끊긴 중간 상태 때문에 끌기를 막지는 마세요.

다만 **‘회사 레벨로 문 +1’은 보류**를 권합니다. 문이 늘면 지름길이 생기거나 강제 우회가 풀릴 수 있어, 추가 문이 항상 좋은 보상이 되지 않습니다. 지금은 판별 고정 수가 낫습니다.

**3. 탐험 규칙의 구체안**

| 항목 | 추천 규칙 |
|---|---|
| 방문 기준 | **분대별로 방문한 방**을 기록. 다른 문으로 연결돼 있어도 이미 방문한 방은 새 탐험 후보에서 제외 |
| 분기 우선순위 | 미방문 이웃 방 → 그중 **바로 옆 방의 미끼가 강한 쪽** → 동률이면 화면 기준 **왼쪽·위·오른쪽·아래** |
| 되돌아오기 | 미방문 이웃이 없으면 직전에 들어온 부모 방으로 복귀. 복귀한 방에서 남은 미방문 이웃을 다시 확인 |
| 보물방 | 처음 진입하는 즉시 탐험 종료. 보물방도 탐험 중에는 일반 후보로 취급 |
| 분대 나눔 | **동률 후보끼리만** 분대 번호순으로 번갈아 배정. 2갈래면 1·3분대 왼쪽, 2·4분대 오른쪽 |
| 다른 분대가 지나간 방 | 뒤 분대에게는 미방문 상태. **방문 기록을 공유하지 않음** |
| 전투 속도·사망 영향 | 먼저 도착한 순서로 분기를 배정하지 않음. 분대가 죽어도 다른 분대의 배정 순서는 유지 |
| 경로선과 실제 이동 | 편집 완료 시 같은 규칙으로 분대별 이동 목록을 만들고 양쪽에서 사용. 전멸한 분대는 그 지점에서 이동 종료 |

여기서 **“왼쪽부터”는 진행 방향 기준이 아니라 화면 기준**이어야 합니다. 돌아 나올 때 기준이 뒤집히면 읽기 어렵습니다.

또한 탐험은 방문 이력에 따라 같은 방의 다음 목적지가 달라집니다. 이전 초안의 **방마다 고정된 다음 방 목록만으로 처리한다는 가정은 버려야 합니다.**

**4. 꼼수 방지 최소 규칙 3개**

수치는 실험용 제안입니다.

| 규칙 | 막는 문제 |
|---|---|
| **입구→보물방 연결 필수**. 고립된 방은 허용하되, 그 안의 시설은 전투 기여에서 제외·흐리게 표시 | 문 다 막기, 고립 시설의 전투력 부풀리기. 방별 최소 문 수는 불필요 |
| **분대별 왕복 포함 문 통과 최대 18회**. 넘는 배치는 확정 불가 | 지나치게 긴 미로. 1분 초과는 방어 성공으로 인정하지 않아 시간 끌기 차단 |
| **같은 함정은 같은 분대에 최대 2회 발동**. 해당 전투 안에서 유지 | 길목 함정 반복 발동 꼼수. 왕복의 이득은 일부 보존 |

방당 최대 문 수까지 추가할 필요는 없습니다. 첫 실험에서는 판 전체 문 수와 이동량 제한으로 충분한지 확인하면 됩니다.

**5. 최소 실험 다시 정의**

| 항목 | 제안 |
|---|---|
| 판 | **가로 3 × 세로 4, 12방, 1층**. 입구·보물방 고정, 전부 1칸 방 |
| 문 | 내부 문 **12개 고정**, P1 방식. 외벽 배치 금지 |
| 시설 | 함정 2개·대기실 1개·미끼 1개 고정. 끝방 함정과 되돌아오는 길목 함정을 비교할 수 있게 배치 |
| 조작 | 문 이동·경로 미리보기·되돌리기·실행만 |
| 비교 | 같은 침입자 3분대로 편집 전후 비교. 직행·짧은 곁방 왕복·긴 우회 배치를 준비 |
| 측정 | 다음 분기와 복귀 방향 예측, 놓기 성공률, 금지 배치 횟수, 편집 시간, 문 통과 수, 함정 발동 수, 보물방 도달 인원 |
| 성공 신호 | 3명에게 각 3번 물었을 때 **7/9회 이상 경로 예측**, 도움 없이 문 이동 성공, 결과를 보고 이유 있는 재배치 시도 |
| 실패 신호 | 선만 따라 무작정 이동, 문을 반복해서 잘못 놓음, 왕복 피해를 이해하지 못함, **가장 긴 길이 일관되게 최선** |

**1인 개발 관점에서는 문 추가 해금과 방 합치기를 붙이기 전에, 이 판 하나에서 ‘함정을 거치는 순서’가 ‘길을 늘리는 양’보다 중요한지 먼저 검증하길 권합니다.** 길이만 늘리면 이기는 구조라면 콘텐츠를 늘려도 같은 해법이 반복됩니다.
