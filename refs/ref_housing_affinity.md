# 참고 게임 4: 집 꾸미기·호감도 — 쿠키런: 킹덤 · 동물의 숲 포켓 캠프 (2026-10-22)

> 조사 방식: ③ 총괄 지식 + ① 웹 검색(위키·공략). ego 안 씀. 구조만 참고.
> **사용자 방침: 집 꾸미기는 간결하게.** 그래서 "자유 배치"가 아니라 "적은 칸 + 점수 + 좋아하는 물건"만 가져옴.
> 출처: Pocket Camp 위키·Pocket Gamer 공략·닌텐도 공식 페이지, 쿠키런: 킹덤 공략(Sportskeeda·ProGameGuides·Pocket Gamer)

## 동물의 숲 포켓 캠프 (컴플리트, 모바일)
| 요소 | 내용 |
| --- | --- |
| 부탁 → 친밀도 | 동물이 올 때마다 부탁은 **최대 3개**만 들어줄 수 있음 + 대화로 친밀도 상승 |
| 좋아하는 가구 | 친밀도 단계마다 **특정 가구를 만들어 달라는 부탁** → 놓으면 보상 |
| 초대 | 친밀도 + 그 동물이 원하는 가구를 모두 캠프에 놓으면 **캠프에 초대**(머묾). 들어온 뒤엔 가구를 치워도 됨 |
| 머무는 수 | 캠프에 최대 10명, 넘으면 바꿔 넣기 |

## 쿠키런: 킹덤
| 요소 | 내용 |
| --- | --- |
| 장식 점수 | 장식을 놓을 때마다 **점수**(큰 것일수록 많이). 성 레벨업 조건 |
| 랜드마크 | 가장 비싼 장식. **놓으면 효과**(생산 빨라짐, 쿠키 능력치 상승), 레벨업 가능. 패스 한정은 자원 생산 |
| 왕국 배치 | 자유 배치(바닥·물길까지) → 꾸미기 좋아하는 사람은 오래 함, 아닌 사람은 귀찮음 |

## 간결하게 옮기면 (우리 방식 후보, 확정 아님)
| 원칙 | 내용 |
| --- | --- |
| 자유 배치 없음 | 방마다 **가구 자리 3~5칸**만. 칸을 누르고 고르면 끝 (쿠키런식 자유 배치는 안 함) |
| 점수 하나 | 가구마다 **꾸밈 점수** → 집 등급(셋방 → 오두막 → 저택 → 성)의 조건 |
| 효과 가구 몇 개 | 랜드마크처럼 일부 가구만 효과(몬스터 회복·로열티 +) |
| 좋아하는 가구 | 부대장마다 **좋아하는 가구 1~2개** → 놓으면 호감도 상승·대화 해금 (포켓 캠프의 부탁 가구) |
| 부탁 3개 | 부대장 부탁은 한 번에 최대 3개 (포켓 캠프) → 매일 할 일이 짧게 끝남 |

## 가져올 아이디어 (CONTENT_IDEAS에 추가)
- 가구 자리 고정 칸 + 꾸밈 점수 → 집 등급
- 효과 가구(랜드마크)
- 부대장이 좋아하는 가구 → 호감도·입주
- 부탁은 한 번에 3개까지
