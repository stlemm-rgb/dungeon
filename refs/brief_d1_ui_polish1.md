## 1. 끌기 그림 위치 (메모 2 — **마우스·손가락 둘 다 불편**)
- 사용자 말: "문과 대기실이 마우스 클릭(손가락) 위쪽에 위치해 있어서 조작감이 불편". 지금 `build.js` `LIFT = 64`(터치), 마우스는 0이라고 돼 있지만 마우스에서도 그림이 커서 위에 떠 보인다 → 먼저 **왜 마우스에서도 위로 보이는지**(CSS transform 기준점, ghost 크기, 판정점 `drag.y - drag.lift` 등) 원인을 찾아 보고.
- 바꿀 방향(모바일 표준):
  - **판정점 = 손/커서 끝 그대로** (위로 띄우지 않음). 놓일 곳 = 손이 가리키는 곳.
  - 끄는 그림은 **손 위치에 붙어 작게**(문: 짧은 막대, 시설: 작은 아이콘) — 손가락에 가려도 괜찮게.
  - 대신 **놓일 칸·벽 자체를 판에서 밝게 강조**(지금 초록/빨강 표시를 더 분명하게, 손가락 밖에서도 보이게). 거절 이유 글(small)은 손가락에 가리지 않는 곳(예: 아래 도구 영역 합계 줄 자리나 판 위쪽 고정 띠)에.
  - 판 가장자리 자동 스크롤은 유지(판정점 기준으로).
- 누르기 → 칸/벽 누르기 방식은 그대로.

## 2. 튜토리얼 말풍선 = 오버레이 (메모 3)
- 지금 `#tut`이 흐름 안에 있고 `--tut-h`만큼 아래를 비워서, 말풍선이 나오거나 사라질 때 **판·버튼이 밀리고 움직인다**.
- 바꿀 것: 말풍선을 화면 위에 **겹쳐 띄우기**(position fixed/absolute, 하단 탭 바로 위). 나오고 사라질 때 아래 화면 배치가 **한 픽셀도 안 움직이게**. `--tut-h`로 아래를 비우던 곳(`#toasts` bottom, 전투 화면 padding 등)은 정리.
- 말풍선이 가리는 곳: 튜토리얼이 반짝이게 하는 버튼·칸이 말풍선에 가리면 안 된다. 가리면 말풍선을 위쪽으로 옮기거나(위·아래 자리 두 개), 반투명/접기 중 단순한 쪽으로. 건설 모드 아래 도구([건설] 버튼)와 겹치는 경우를 꼭 확인.
- 등장 애니메이션은 겹쳐 뜨는 모양으로(아래 화면은 그대로).

## 확인
- 헤드리스 Chrome(`tools/cdp.js`, 390×844 터치 + 1280 마우스): 문 끌기·시설 끌기에서 **판정점이 손/커서 끝과 같은지**(끝 좌표의 벽/칸에 실제로 놓이는지) 확인. 튜토리얼 켜진 새 게임에서 말풍선이 나오기 전후로 판·버튼의 `getBoundingClientRect()`가 **같은지** 숫자로 확인. 반짝이는 대상이 말풍선에 안 가리는지.
