## 3-A. 던전 가치 공식 적용안 (2026-10-20)

> 분석 원본: `REA/analysis/03-A-value-formula.md`
> **숫자는 출발점일 뿐이다.** 지금 방침은 "균형 맞추기 보류, 기능 위주"(HANDOFF)이므로, 여기서는 **함수의 모양**만 정하고 숫자는 나중에 측정 도구로 맞춘다.

### 풋볼 에이전시 몸값 공식 한 줄 요약
`몸값 = 상한압축( 130만 × 5^((능력−62)/10) × 계수 15개 )`
계수(나이·폼·출전·계약 기간·부상·화제성 …)는 대부분 0.5~1.4 사이이고, 함수는 **값과 함께 계수별 내역**을 돌려준다. 주급·구단 예산·요구액도 같은 곡선에서 나온다.

### 지금 A7과 비교

| | A7 지금 | 풋볼 에이전시 방식 |
|---|---|---|
| 가치 계산 | 덧셈: 시설 값(칸당 10·5) + 몬스터 기본값 | **기준값 × 계수들** |
| 몬스터 레벨 | 체력·공격만 +20%/레벨, **가치는 그대로** | 능력이 오르면 가치가 지수로 오름 |
| 안 쓰이는 구역 | 가치에 그대로 들어감 | "안 뛰는 선수는 싸다" (출전 계수 0.82~1.05) |
| 의뢰 조건 (요구 가치·보수·선금) | 명성마다 각각 +50 | 하나의 곡선에서 파생 |
| 판매 대금 | 가치의 절반 | 같은 함수의 결과에 비율 |
| 왜 이 값인지 | 화면에 합계만 | 계수 내역 → **감정서**로 보여 줌 |
| 끝없는 성장 | 막는 장치 없음 | 상한 압축 (부익부 브레이크) |

### 제안 1: 던전 가치 함수 하나
```js
// 어디서든 이 함수만 부른다: 납품 감정, 의뢰 조건 검사, 판매 대금, 랭킹, 화면 미리보기
dungeonValue(layout, units, ctx) → { value, base, f }

base = Σ 시설 기준값 + Σ 몬스터 기준값
  시설 기준값  = 시설 단가 × 칸 수 × (시설 등급 곡선)          // 나중에 시설 강화가 생기면 등급
  몬스터 기준값 = 종류 단가 × 밑^(레벨 − 1)                       // 예: 밑 1.2 → 레벨업이 가치에 반영

f = {
  fit:       요구 일치 (속성·비율 조건을 넘긴 만큼)          예: 1 ~ 1.3
  used:      침입자가 실제로 지나가는 구역 비율 ("안 지나감" 감점)   예: 0.8 ~ 1.05
  defense:   3일 방어 실적 (막은 비율, 도망치게 한 수)        예: 0.9 ~ 1.3
  leader:    부대장 스킬 보너스 (GAME_PLAN: 부대장은 가치에 직접 안 들어가고 올려 줌)  예: 1 ~ 1.2
  mood:      마왕 만족도                                       예: 0.85 ~ 1.15
  ceiling:   상한 압축 비율 (장마다 상한, 마왕 던전 납품 시 해제)
}
value = 상한압축(base × Π f)
```
- `used` 계수가 A7의 "안 지나감" 표시와 바로 이어진다. 길에 없는 구역에 돈을 쓰면 가치가 덜 오른다. 플레이어에게 "길을 설계하라"는 신호가 된다.
- `ceiling`은 GAME_PLAN의 "장마다 명성 상한, 마왕 던전 납품 시 상한 해제"와 같은 장치다.

### 제안 2: 돈은 모두 같은 곡선에서
```js
요구가치(명성)  = V0 × 밑^(명성 / 간격)          // 의뢰서의 "가치 N 이상"
선금           = 요구가치 × a                     // 예: a = 0.6
보수           = 요구가치 × b                     // 예: b = 0.4
판매 대금       = 납품 가치 × c                    // A7: c = 0.5
침입자 강도     = 같은 명성 곡선                    // 명성이 오르면 같이 오름
```
→ 지금은 명성마다 요구 +50, 보수 +50, 선금 +50이 따로 정해져 있다. 곡선 하나로 묶으면 **명성 조정 한 번에 경제 전체가 같이 움직인다.**

### 제안 3: 감정서 화면
`f` 내역을 납품 → 감정 화면에 한 줄씩 보여 준다. 예: "요구 일치 ×1.2 · 지나가지 않는 구역 ×0.9 · 방어 실적 ×1.1". 플레이어는 다음 회차에 무엇을 고칠지 알게 되고, 밸런스를 볼 때도 같은 내역을 쓴다.

### 넣는 시점
| 무엇 | 언제 |
|---|---|
| `dungeonValue` 함수 모양 + 감정서 내역 | A7 다음 시안 또는 2단계 시작 때 (숫자는 지금 A7 값을 그대로 기준값에 넣으면 된다) |
| 몬스터 레벨을 가치에 반영 | 친위대·부대장 설계 때 |
| 상한 압축, 곡선으로 묶은 의뢰 조건 | 밸런스 단계 (측정 도구로 숫자 결정) |

### 풋볼 에이전시 경기 계산 한 줄 요약
팀 전력(베스트 11 평균, 빈자리는 35로 계산) → 전력 차로 기대 득점(`1.4 × e^(0.055×차이)`, 상한 3.2) → 포아송으로 실제 득점 → 골·도움을 능력 비례로 나눠 줌 → 선수마다 평점·폼·부상·알림.
그리고 **큰 경기 카드**: 경기 전에 "PK를 찰까 / 연장을 뛸까"를 미리 고르면, 그 경기에서 성격이 반영된 확률로 결과가 터진다.

### 지금 A7과 비교

| | A7 지금 | 풋볼 에이전시 |
|---|---|---|
| 방식 | 방마다 침입자·몬스터가 체력을 한 번씩 깎는 틱 계산 | 팀 단위로 결과를 먼저 정하고 개인에게 나눔 |
| 무작위 | 없음 (같은 배치 = 같은 결과) | 기대값 주위에서 포아송 + 평점 잡음 |
| 개인 평가 | 처치 수 → 경험치 (참가 1 + 처치 1) | 평점 = 기대 대비 성과 → 폼(이동 평균) |
| 결과 보여 주기 | 단계 문장 목록 | 사건 큐 → 결과 팝업 (해트트릭, 최우수 선수…) |
| 플레이어 개입 | 없음 (GAME_PLAN: 2단계는 자동만) | 미리 고르는 카드 → 경기 중 해소 |

### 총괄 조언 (인디 개발 관점): 퍼즐 게임은 예측 가능해야 한다

풋볼 에이전시의 무작위는 **이야기**를 만드는 장치다(이변, 기복 있는 선수). dungeon의 재미 중심은 **"마왕 요구 맞추기 퍼즐 + 침입자 유도"**다. 퍼즐은 플레이어가 결과를 내다볼 수 있어야 재미있다. A7의 "문 위 인원 미리 보기"가 바로 그 장치다.

→ **이동과 함정은 지금처럼 결정적으로 두고, 무작위는 좁게 쓰기를 추천한다.**
- 무작위를 넣는다면 전투 결과 쪽에만 작은 폭(예: 피해 ±10%)으로 넣는다.
- 아니면 무작위 대신 **침입자 구성의 다양성**(누가 오는지)을 의뢰서에서 미리 보여 준다. 계획할 거리는 늘고 예측은 유지된다.

### 가져올 것

| # | 가져올 것 | dungeon에서 | 언제 |
|---|---|---|---|
| 1 | **집계 → 분배** 계산 | 지금 틱 계산은 시안에 좋다(과정이 보임). 2단계에서 측정 도구(autoplay)로 수천 판을 돌리거나 무한 모드가 생기면, "방 전력 차 → 사상자 수"를 먼저 정하고 처치·경험치를 몬스터에게 나누는 방식이 훨씬 빠르다. **같은 함수에 "빠른 계산" 모드를 하나 더** 두는 식 | 2단계 |
| 2 | **빈자리 페널티** | 대기실 자리를 다 못 채우거나 부대장 지휘를 못 받은 부대는 약하게 (GAME_PLAN 총괄 제안 "지휘받지 못한 부대는 약해짐"과 같은 장치) | 부대장 설계 때 |
| 3 | **기대 대비 활약 점수** | 몬스터마다 "기대보다 잘 막았나"로 점수 → 최우수 몬스터 표시, 경험치 가중. 약한 몬스터에게도 성장 이야기가 생긴다 | 3단계 |
| 4 | **컨디션 = 이동 평균** | 최근 전투 활약이 컨디션에 쌓임 (`컨디션×0.75 + 점수×0.25`) | 3단계 |
| 5 | **사건 큐** | 첫 처치, 연속 처치, 레벨업, 보스방 도달, 도망친 수 → 정산 팝업 큐(적용표 4순위)로 | 2단계 |
| 6 | **사전 지시 카드** | GAME_PLAN "자동 진행 + 카드 개입"의 첫 형태. 실시간 조작 화면 없이 **건설 단계에서 카드를 미리 걸어 두고, 조건이 맞으면 침입 중에 해소**. 예: "보스방 앞에서 부대장 출격 (안전: 체력 보존 / 도전: 부대장 성격으로 확률 처치)", "함정 과부하 (피해 2배, 함정이 망가질 확률)" | 3단계 |
| 7 | **몬스터 전투 기록** | 전투마다 `[회차, 날, 방, 상대 수, 처치, 받은 피해, 점수]` 짧은 튜플을 최근 N개 → 몬스터 상세·도감 | 3단계 |
