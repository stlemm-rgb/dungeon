# UI 배치 참고: 현장 화면 (2026-10-23)

> 사용자 소감 "UI 배치가 난잡, 레퍼런스 필요" → 세로 단면 경영 게임 2개의 **배치 원칙만** 정리. 모양·색은 우리 것.
> 출처: BlueStacks Idle Miner Tycoon 공략(https://www.bluestacks.com/blog/game-guides/idle-miner-tycoon/idt-tips-tricks-en.html, 초보 가이드 idt-beginner-guide-en.html), TrueAchievements Fallout Shelter 공략(https://www.trueachievements.com/game/Fallout-Shelter/walkthrough/3), Steam 토론. 스토어 그림은 광고 그림이라 UI 확인 불가 → 글 출처 + 알려진 배치.

| 게임 | 배치 원칙 | 우리에게 |
| --- | --- | --- |
| Idle Miner Tycoon (세로) | 화면 = 세로 광산 단면이 거의 전부. 층(갱도)마다 **작은 레벨 버튼 하나**만, 누르면 아래에서 업그레이드 창. 맨 아래 **새 갱도 버튼**. 화면 아래 줄에 부스트·상점 등 공용 버튼 | 층 안에 버튼을 여러 개 두지 않는다. 층 = 정보 + 눌러서 열기 |
| Fallout Shelter | **건설 버튼 하나(망치)** → 건설 모드: 지을 수 있는 빈칸이 표시(망치 아이콘) → 방 고르기. 층마다 버튼 없음 | 건설은 "모드"로: 하나의 버튼 → 빈 구역이 빛남 → 시설 고르기 |

## 공통 원칙
1. 층 수가 늘어도 **버튼 수는 그대로** (층마다 건설·출진 버튼 X).
2. 가장 자주 누르는 버튼(우리: 다음 주)은 **한 자리, 크게**.
3. 지을 수 있는 곳은 화면에서 직접 보여 준다(빈칸 표시).

## 시안
비공개 페이지 "현장 화면 배치 3안" https://claude.ai/artifact/G69njyyfsW1Nmn6LNV3t9e
- A: 아래 작업 줄 고정(건설·출진·포로수용소), 다음 주는 위 진행표 안
- B: 건설 모드(Fallout Shelter식) — 층 안 빈 구역에 "+ 짓기", 아래 시설 띠, 층 누르면 출진
- C: 엄지 영역 — 아래에 [건설][다음 주 크게][출진], 위는 상태 + 진행 막대만, 층 안 구역이 바로 보임
