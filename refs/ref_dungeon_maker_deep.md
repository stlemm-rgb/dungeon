# 참고 게임 심층: Dungeon Maker: Dark Lord (던전메이커) — 전체 분석 (2026-10-22)

> 조사 방식: ① 웹 검색 + 앱스토어 페이지 + ② ego로 TouchArcade 공략·리뷰 전문, TouchArcade 포럼 공략 목차 읽기 + 기존 `refs/ref_mobile_dungeon_games.md`. 특정 부분에 얽매이지 않고 전체를 봄.
> 출처: App Store, TouchArcade 공략(2018-05)·리뷰(2018-06, Sarah Saunders), TouchArcade 포럼 [Guide & Tip], TapTap(한국어 소개), GamerBraves 요약, Spark(다운로드 추정), 구글 플레이.

## 1. 정체와 성과
- **한국 인디 GameCoaster**(전작 Dungeon Defense). 2018년 5월 iOS·안드로이드. 유료 3.99달러 + 인앱(해금 묶음 5~27달러, DLC "카드 게임" 2020).
- 2018 **구글 인디 게임 페스티벌 TOP 10**, "올해를 빛낸 인디 게임", 일본 앱스토어 유료 1위·한국 전략 2위·중국 전략 3위(팬 정리), TouchArcade 한 달간 인기 게임 1위권.
- 구글 플레이 4.6점(5.4만 평가)·50만+, 앱스토어 4.7점. **가로 화면**.
- 서버 없음, 모든 데이터는 기기에만, **완전 오프라인**.

## 2. 컨셉
> **"악당(마왕)이 되어, 작은 던전을 키우며 100일 동안 쳐들어오는 용사를 막는 로그라이크."**
- 기본 발상은 Dungeon Keeper("하지만 망한 무료판과는 다른")와 비슷 — 리뷰어.
- 장르 섞기: **로그라이크(카드로 길 고르기) + 타워 디펜스(방 배치) + 카드 + 전략 + 몬스터 합성**.

## 3. 분위기·그림
- **한국 만화(만화·웹툰) 풍**, 귀엽고 빠른 전투, 위에서 내려다보는 전투 화면.
- 고를 수 있는 **마왕은 모두 개성 있는 여성 캐릭터** → 리뷰어가 "내 최애 마왕 타니아"라고 부를 만큼 **캐릭터 애착이 반복 플레이를 끌고 감**.
- 톤은 가벼운 악당 코미디("몬스터는 마왕을 위해 존재하니 목숨은 소모품").

## 4. 한 판(런)의 구조
| 요소 | 내용 |
| --- | --- |
| 목표 | **100일 버티기** = 다음 난이도 해금 (마법의 숫자). 대충 하면 40일 전에 죽음 |
| 하루 | 카드 판에서 **3장 중 1장** 고르기. 왼쪽·오른쪽 카드를 고르면 판 위에서 옆으로 이동 → 원하는 카드에 다가가는 **짧은 계획** |
| 20일 주기 | 1일째는 전투 3장만 / **19일째는 던전(휴식·강화) 카드만** / **20일째 보스 전투** → 끝나면 더 어려운 20일이 다시 깔림 |
| 카드 7종 | 전투(금 + 보상: 방·장비·몬스터 알·합성·희생) / **정예 전투**(+ 유물) / 던전(마왕 회복·방 강화·몬스터 훈련 중 하나) / 상인(몬스터·방 사기, 마왕 강화, 합성) / 이벤트(좋거나 나쁘거나, 열에 아홉은 안 싸움) / 보물(유물 3개 중 1개) / 보스 |
| 리듬 | **싸우지 않고 넘기는 날**(던전·이벤트·보물)이 있어 체력 관리 → "싸울까 쉴까" |

## 5. 던전
| 요소 | 내용 |
| --- | --- |
| 시작 | **3×3 칸**, 가운데 전투 방 하나 + 몬스터 3마리. 판을 이어 가며 칸을 넓힘 |
| 방 4종 | **전투 방**(몬스터 최대 3, 몬스터 강화·용사 약화. 거대화 방은 1마리 ×2) / **함정**(몬스터 없음, 들어오는 용사에게 피해·상태 이상 → 입구 쪽 추천) / **시설**(용사에겐 효과 없고 마왕·몬스터에게 이득, 예: 부화장 = 알 레벨 +1 → 안쪽 추천) / **제단**(용사에게 이득인 나쁜 방, 이벤트로 억지로 생김 → 빨리 치우기) |
| 방 강화 | 던전 카드로, 또는 **아무 시설 카드나 재료로 써서** 레벨업 |
| 배치 | 함정은 앞, 시설은 뒤. 배치가 중요하지만 "전부를 좌우하진 않음" |

## 6. 몬스터·마왕
| 요소 | 내용 |
| --- | --- |
| 몬스터 알 | 깨면 **3마리 중 1마리** 고르기 |
| 합성 | 몬스터 둘을 합쳐 새 몬스터 / 특수 몬스터·함정 조합표 |
| 희생 | 몬스터를 바쳐 **마왕 능력치** 강화 |
| 훈련 | 던전 카드로 몬스터를 정예로 |
| 장비 | 몬스터에게 장비 |
| 마왕 | 7~9명, 각자 고유 스킬. **전투 중 화면을 탭해 기본 공격**, 아이콘을 눌러 마나 스킬(마나는 전투 중 빠르게 참) → 보는 전투에 **손으로 끼어드는 맛** |
| 유물 | 200+개, 정예·보스·보물에서. 런 안에서 능력치 상승 |

## 7. 런 밖 성장 (메타)
- **마석(데빌 스톤)**을 모아 마왕·유물·요소 해금(심연 상점). 자동 스킬 같은 핵심 편의도 해금 대상(느리다는 불평).
- 100일 달성 → 다음 난이도.
- 스토리 모드(30일 제한) 엔딩을 보면 일반 모드에 그 캐릭터 해금.
- 계승(Succession) 묶음 = 다음 판에 일부 인계(인앱 이름으로 확인, 세부 미확인).

## 8. 과금·운영
- **"참을성 없는 사람을 위한 인앱"**: 인앱으로 여는 것은 **모두 플레이로 열림**, 개발사가 상점에 그 사실을 정직하게 표시 → 호평. 리뷰어: "돈으로 다 열었더니 성취감이 사라졌다".
- 출시 직후 **잦은 업데이트**(밸런스·카드 묶음·업적 98개 추가) → "만들고 떠나지 않는 개발사" 평판. 2020 DLC, 이후 유지 보수 위주(2025 유니티 보안 업데이트까지).

## 9. 비평
- "헷갈리고 투박하고, 콘텐츠가 너무 많을 정도"(Reddit) — 그래도 최애 게임.
- 핵심 편의(자동 스킬)가 느린 뽑기식 해금 뒤에 있음, 묶음 가격이 비쌈(2018 리뷰).
- 처음은 쉽게 배우지만 깊이가 놀라움(GamerBraves).

## 10. 왜 성공했나 (총괄 분석)
1. **검증된 틀 섞기**: 로그라이크 카드 길(Slay the Spire식) × 타워 디펜스 × 몬스터 수집·합성 → 매 판 다른 조합.
2. **명확한 목표 숫자**: "100일". 20일마다 보스라는 **리듬**.
3. **캐릭터 애착**: 만화풍 여성 마왕들 → 다시 할 이유.
4. **정직한 과금 + 오프라인**: 1인·소규모가 감당할 수 있는 구조(서버 없음)이면서 평판을 얻음.
5. **출시 직후 잦은 업데이트 + 커뮤니티**(포럼 공략이 자생) → 입소문.
6. 약점은 **정보 과다·복잡함** → 우리는 "생각 없이 넘기기·보기"로 그 반대편을 노릴 수 있음.

## 11. 우리에게 반영 (CONTENT_IDEAS에 추가)
| 영역 | 아이디어 |
| --- | --- |
| 리듬 | 의뢰 안에 **주기와 보스 주**: N주마다 정예·보스 침입, 그 전 주는 휴식·강화 주 |
| 카드 | 매주 카드 **3장 중 1장**(전투·정예·휴식·상인·이벤트·보물), 싸우지 않고 넘기는 주가 있음 |
| 시설 | **나쁜 방(제단)**: 이벤트로 억지로 생기는 침입자 유리 방 → 치우는 재미 (둥드 손해 시설과 같은 결) |
| 시설 | 남는 시설 카드는 **다른 시설 강화 재료**로 |
| 몬스터 | 알 = 3마리 중 1마리 고르기 / 몬스터 **희생 → 소장·공방 강화** |
| 전투 | 보는 전투에 **손으로 끼어드는 버튼**(소장·부대장 스킬, 마나처럼 차오름) |
| 목표 | 명확한 숫자 목표(예: "작품 100개", "평판 100") |
| 캐릭터 | 고를 수 있는 **개성 있는 주요 인물**(부대장·의뢰인)이 반복 플레이 동기 |
| 과금 | 인앱으로 여는 것은 모두 플레이로도 열림을 **상점에 명시** |
| 운영 | 출시 직후 잦은 업데이트, 공략 커뮤니티가 생기게 |
| 차별 | DM의 약점(정보 과다)의 반대: 정보는 줄이고 보는 재미·손맛 |
