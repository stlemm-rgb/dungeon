## 할 일 (API 18-7 그대로)
1. 보스 판 `P.battleInput(plan, { cards: true })` (create·restore 둘 다). 일반 판은 그대로.
2. `S.pick`이 있으면 전투 정지 + 카드 창: 판 위 위기 위치 강조, 아래쪽에 후보 카드(이름 · 효과 한 줄 · 대상), "카드 n/2", [넘기기]. 판을 가리지 않게 판과 창 영역을 나눔 (390×844).
3. 방을 고르는 카드(임시 수비대·긴급 작동): `pickSelect` → 창 접고 판에서 가능한 방만 강조 → 방 누름 → [사용] `pickUse` / [취소] `pickCancel`. 연막은 바로 [사용].
4. 창이 열릴 때와 고르기·취소·사용·넘기기 직후마다 `checkpoint()` 저장. 새로고침 뒤 `sel`이 있으면 대상 고르기 화면부터.
5. 효과 표시는 실제 사건만: 연막 = 분대 위 연막 + 남은 초, 임시 수비대 = 새 `S.dens[z]` 부대 점 다시 그리기 + "임시" 표시, 긴급 작동 = 함정 번쩍 + 피해 숫자. 움직임 줄이기에서도 아이콘·숫자로 같은 정보.
6. 보스 결과 창에 `show.cards[].text` 한 줄씩 (카드를 안 썼으면 줄 없음).
7. 검사: d1_drive.js 새 흐름 한 바퀴에 카드 한 번 이상(창 → 방 고르기 → 취소 → 사용, 넘기기 한 번)과 새로고침 복원을 넣는다. 빨리 감기 단계(API 직접 호출)는 카드 없이 그대로.
