## 핵심 (기획서 요약 — 세부는 기획서)
1. **하단 탭 3개: 회사 · 현장 · 군단.** 마계·내 집·가운데 홈/다음 주/운영 버튼 없앰. 군단은 첫 전투 정산 전 잠김 표시.
2. **현장 = 같은 판 4상태**: 운영(일반 판 자동 반복, 최근 정산 한 줄, [출진][건설], 큰 [보스 도전 n]) / 건설(판 크게, 확정·취소) / 보스 도전(탭 이동 막음) / 보스 결과(요약 + 분대별 펼침, 실패 [배치 고치기][다시 도전][일반 침입 재개], 성공 [다음 보스 도전][일반 침입 재개], 5/5면 [납품]). 지금의 "정비" 화면은 운영에 합친다. 출진·조달·보충은 현장 [출진] 창으로.
3. **확정된 선택**: ① 현장 밖이면 일반전 멈춤, 돌아오면 이어 감 ② [납품] 실행은 현장 5/5 결과 하나, 회사는 정산·안내 ③ 데모에 없는 입구는 숨김(취소선 버튼 없앰) ④ 군단 = 부족·친위대 하위 탭, 2열 카드 + 아래 상세 ⑤ 보스 결과 요약 + 분대별 펼침 ⑥ 건설·강화·출진 확정 = 진행 중 일반 판 버리고 바로 새 판(지금 로직 그대로).
4. **상단 바·단계 막대·다음 목표 한 줄**(기획서 7절). 전투력은 의뢰 없으면 `—`. 재화는 화면에 맞는 것만.
5. 카드: 이번엔 숨김(자리만 생각). 튜토리얼: 지금처럼 꺼 둠, 옛 "다음 주" 안내 문구는 지움(새 튜토리얼은 나중).
6. 화면은 흐름 시험 켜진 경우(`FLOW.on = true`)만 지원하면 된다. 옛 주 단위 화면 코드는 지워도 된다(로직은 남아 있음).
7. 390×844 기준: 판 전체·주요 버튼이 가려지지 않음, 가로 넘침 0, 콘솔 오류 0. 1280 폭도 깨지지 않게.

## 검사 도구
- `test_d1_flow.py`·`d1_drive.js`를 새 동선으로: 새 게임 → 회사 의뢰 수락 → 현장 운영 → 건설·문 끌기·확정 → 보스 실패 → 배치 고치기 → 재도전 성공 → (API로 빨리) 5/5 → 현장 [납품] → 회사 정산 → 데모 끝, 새로고침 복원, 탭 이동 멈춤/이어 감, 콘솔 오류 0.
- `shots.py` D1 장면은 새 화면 기준(회사·현장 운영·건설·보스 중·보스 결과 390 + 회사 1280 정도). **기준 사진 `--update`는 하지 마라**(총괄이 눈으로 보고 갱신). 새 사진은 `tools/shots/out/d1/`에 남기고 실패는 그대로 보고.
- core-dev가 같은 때 마석 숫자를 바꾸므로, 마석 숫자에 기대는 검사 문장은 숫자를 하드코딩하지 말고 API에서 읽어 비교.
