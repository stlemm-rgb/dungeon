# 참고 게임 7: Idle Miner Tycoon (2026-10-22, 모바일 세로)

> 조사 방식: ① 웹 검색(공략·개발사 발표·GDC 요약) + ② ego로 구글 플레이(평점·다운로드, 스크린샷 1장) + ③ 총괄 지식.
> 스토어 스크린샷은 가로 홍보 그림이지만 **실제 플레이는 세로**(갱도가 위아래로 길게, 총괄 지식).
> 출처: BlueStacks·AppGamer 공략, Kolibri Games 인터뷰(Pocket Gamer.biz·GameAnalytics), GDC 2019 요약(mobilefreetoplay), PlaytestCloud 사례, 구글 플레이.

## 무엇
- Kolibri Games(독일). 구글 플레이 4.5점, **1억+ 다운로드**. 방치형 광산 경영의 대표작.
- 화면: **세로로 긴 광산 단면**. 층(갱도)마다 광부가 캐고 → 왼쪽 **엘리베이터**가 층을 돌며 실어 올리고 → 위 **창고**로 운반해 돈이 됨.

## 구조
| 요소 | 내용 | 우리에게 |
| --- | --- | --- |
| 세 부분 맞추기 | 갱도·엘리베이터·창고 레벨이 따로. **가장 느린 곳이 전체를 막음**(병목) → 고르게 올려야 | 현장 층 구역 ↔ 입구 ↔ 보물방의 흐름. 단, 우리는 "생각 없는" 쪽이라 병목 퍼즐은 가볍게 |
| 아래로 새 갱도 | 돈이 모이면 **한 층 더 파서** 새 갱도를 염. 깊을수록 비싸고 많이 범 | 현장 = 층을 파 내려가며 구역 열기 (Fallout Shelter와 같은 결론) |
| 매니저 | 층마다 매니저를 앉혀야 자리를 비워도 돌아감(방치 수입). 등급 3단계 + 특수 매니저, **스킬을 눌러 잠깐 부스트** | **지점장·층 담당 부대장**. 부대장 스킬 = 잠깐 강해지는 버튼 (전투 중 카드 대신 쓸 수도) |
| 프레스티지 | 광산을 처음으로 되돌리는 대신 **생산 배율 영구 상승**(광산당 최대 5번) | 우리 **납품(초기화) + 남는 것**과 같은 구조 → 납품할수록 회사 배율이 오르는 "느낌"을 숫자로 |
| 대륙 8개 × 광산 5개 | 새 광산은 새 대륙에서, **새 광산을 빨리 여는 게 이득** | 지역(포탈) × 지역마다 의뢰 몇 개 |
| 연구 | 연구 점수로 영구 보너스 | 공방·재능 트리 |
| 기간 한정 이벤트 광산 | 보상이 걸린 **한정 광산** → 매출이 꺾여 오른 지점(GDC) | Fallout Shelter 시즌 볼트와 같은 결론 → **시즌 테마 부지** 우선순위 높음 |

## 개발사 교훈 (Kolibri)
- **첫날 재방문율(D1)이 전부**: 약 75%(상위 게임 약 40%). D1이 약하면 D30은 불가능.
- 오래 남는 사람은 **두 번째 갱도까지 간 사람** → 첫 10분 안에 "두 번째 것"을 열어 주기. 우리로 치면 **첫 납품을 빨리**(튜토리얼 의뢰 짧게).
- 과금 = "돈 내거나 기다리거나". 지는 상태가 없으니 **진행 속도**를 판다. 광고 보기로 대기 건너뛰기.
- 최소 기능 제품(MVP)으로 먼저 내고 확인. 전작은 60% 만들다 버림.

## 가져올 아이디어 (CONTENT_IDEAS에 추가)
- 층 담당 부대장·지점장 + 누르면 잠깐 부스트하는 스킬
- 납품할 때마다 회사 배율 영구 상승(프레스티지처럼 숫자로 보여 주기)
- 새 지역·새 의뢰를 빨리 여는 쪽이 이득이게
- 첫 10분 안에 첫 납품(두 번째 갱도 효과)
