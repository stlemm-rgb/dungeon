# 참고 게임 8: Reigns (2026-10-22, 모바일 세로)

> 조사 방식: ① 웹 검색(위키백과·GDC 2017 강연 소개·기사) + ③ 총괄 지식(화면·조작 세부). ego 안 씀.
> 출처: 위키백과, GDC Vault "The Casual (but Regal) Swipe"(François Alliot, 2017, 본문은 로그인 필요), AppSamurai 기사, UBC 위키.

## 무엇
- Nerial 개발, Devolver 배급(2016). 휴대폰 세로 + PC. **카드를 좌우로 넘겨** 왕국을 다스림. "틴더 정치(Tinderocracy)"라는 별명.

## 구조
| 요소 | 내용 |
| --- | --- |
| 네 막대 | 위에 교회·백성·군대·재정. **하나라도 바닥나거나 꽉 차면** 왕이 죽고 다음 왕이 이어받음(균형 게임) |
| 카드 한 장 | 위에 질문 글, 가운데 인물 그림(카드), 끌면 카드 위에 **선택 글**(예/아니오 대신 짧은 말)이 나타남 |
| 끌 때 힌트 | 끄는 동안 **영향받는 막대 위에 점**이 뜸(점이 클수록 크게 변함). **오르는지 내리는지는 안 알려 줌** → 생각할 거리는 남기고 정보는 최소 |
| 두 방향만 | 왼쪽 / 오른쪽. 어떤 카드는 양쪽 결과가 같음(그냥 넘기는 이야기 카드) |
| 죽음 → 다음 왕 | 한 판(한 왕)은 몇 분. 죽어도 **목표 달성·새 카드 해금은 남음**, 연도가 계속 이어짐 |
| 반복 인물 | 같은 인물이 계속 나와 관계·이야기가 쌓임 |

## 개발자 교훈 (GDC 소개·기사)
- 첫 시안은 카드가 아니라 **초상화**였는데 "몸으로 느껴지지 않아서" 카드로 바꿈 → 카드로 바꾸자 **튜토리얼이 필요 없어짐**.
- 게임 전체를 "**또 넘길 수 있게**" 넘기기 반복 하나에 맞춰 만듦.
- 조작 제약(두 방향, 짧은 글)을 먼저 정하고 글을 그 안에서 씀. 다만 제약이 이야기의 범위를 막지는 않게.
- 평: 연출·조작은 호평, **시간이 지나면 반복된다**는 평.

## 우리에게
| Reigns | 우리 카드 넘기기 |
| --- | --- |
| 끌 때 영향받는 막대에 점(방향은 숨김) | 끄는 방향의 효과를 **아이콘 하나 + 크기**로만 보여 주기 (지금은 글로 다 보여 줌) → "생각 없이" 넘기기에 맞음 |
| 두 방향 | 우리는 네 방향(확정). 네 방향이 생각을 늘린다면 **일부 카드는 두 방향만 쓰거나 양쪽 같은 이야기 카드** 섞기 (검토 후보) |
| 카드 = 인물 그림 | 이벤트 카드 위 3/4 일러스트 (이미 반영) |
| 반복 인물 | 비서·부대장·단골 모험단이 카드로 반복 등장 |
| 죽어도 해금은 남음 | 납품해도 카드 해금은 남음 → **카드 도감**(본 카드 수집) |
| 한 판 몇 분 | 한 주 전투 짧게 |

## 가져올 아이디어 (CONTENT_IDEAS에 추가)
- 끄는 동안 효과는 아이콘·크기로만 (글 최소)
- 일부 카드는 두 방향만 / 양쪽 같은 이야기 카드 섞기 (검토 후보)
- 반복 등장 인물 카드 (비서·부대장·단골 모험단)
- 카드 도감: 본 카드가 쌓이고 새 카드가 해금됨
