# Codex 2라운드 원문 (2026-10-28, 사용자 새 제안 "계속 진입 + 보스 막으면 던전 레벨업") — 정리본은 debate_ds_restructure_2026-10-28.md

**찬성합니다. 1라운드의 ‘주 단위 턴 유지’ 의견을 변경합니다.** 추천은 **일반 침입은 자동 반복하고, 건설할 때는 멈추며, 플레이어가 보스 도전을 눌러 다음 단계로 올라가는 방식**입니다.

다만 “계속 들어온다”를 **여러 전투가 끝없이 겹치는 구조**로 만들 필요는 없습니다. 처음에는 지금 전투 한 판이 끝나면 다음 판이 자동 시작되는 것으로 충분합니다.

1인 개발이라면 **UI 전체 개편 전에 ‘같은 보스에게 실패 → 문 수정 → 재도전 성공’ 한 바퀴부터 시험**하길 권합니다. 판이 움직이는 만족과 배치를 고치는 재미가 함께 살아나는지 확인해야 화면도 덜 고칩니다.

아래는 문서에 근거한 설계 의견이며, 파일은 수정하지 않았습니다. DS 자료는 스크린샷으로 추정한 기록이므로, 실제 DS 규칙의 검증으로 보지는 않았습니다.

**(가) 퍼즐을 살릴 수 있다. 다만 일반 침입과 보스의 역할이 달라야 한다**

일반 침입은 **내 던전이 작동하는 모습을 보여 주는 흐름**, 보스는 **내 배치가 통하는지 확인하는 시험**으로 삼으면 됩니다.

| 필요한 조건 | 이유 |
| --- | --- |
| 같은 단계 보스는 구성·시드 고정 | 실패 뒤 문을 고쳤을 때, 결과 차이를 배치와 연결할 수 있음 |
| 보스 입장 시 배치·부대 능력치 확정 | 싸우는 도중 강화해서 이기는 방식이 배치 판단을 흐리지 않음 |
| 실패 결과에 도달 위치·함정 피해·격퇴/퇴각 원인 표시 | “약하다”보다 “어디를 고칠까”를 생각하게 함 |
| 문 수정은 무료 유지 | 실패 후 가장 먼저 시도할 행동이 됨 |
| 보스는 기다려서 강화하는 것 외에도 배치로 돌파 가능 | 자동 수입이 퍼즐을 대신하는 것을 막음 |

보스 방어 성공은 현행 규칙과 맞춰 **보물방 도달 없이 격퇴하거나 제한 시간을 버티면 성공**으로 추천합니다. 타이머가 경로를 늘리는 이유가 됩니다. 단, 모든 방 연결·문 개수·통과 한도 검사는 유지해야 합니다.

보스가 여러 분대라면 **한 분대라도 최종 보물방에 들어오면 실패**로 분명하게 표시합니다. 2층에서는 1층 계단 도달을 실패로 세면 안 됩니다.

현재 HANDOFF의 “대기실이 지나치게 강하다”는 문제는 이 시험에 직접 영향을 줍니다. 보스도 대기실 하나에 늘 막히면 퍼즐을 검증할 수 없습니다. 전체 밸런스 조정은 미루더라도, **시험용 보스와 비교할 배치 정도는 차이가 나도록 조정**해야 합니다.

**(나) 총괄안에서 고칠 부분**

가장 크게 반대하는 부분은 **“지금 한 주 전투를 자동 반복하면 경제도 그대로 쓸 수 있다”**는 해석입니다. 반복 장치는 재사용할 수 있지만, 주마다 주던 보상과 회복까지 그대로 빨라지면 다른 게임이 됩니다.

| 쟁점 | 추천하는 모양 | 이유 |
| --- | --- | --- |
| 배치 수정 | [건설]을 누르면 즉시 전투 정지. 수정안은 임시 보관하고 **현재 전투 종료 뒤 확정 적용** | 전투 중 경로를 바꾸지 않으면서, 기다리지 않고 편집 가능 |
| 건설 완료 | 기존 배치로 남은 전투 재개 → 정산 → 새 배치 적용 → 다음 침입 | 화면에 “이번 전투 뒤 적용”을 분명히 표시 |
| 시설 강화·군단 성장 | 전투에 영향을 주는 변경은 같은 경계에서 적용 | 문만 늦게 적용되고 강화는 즉시 적용되는 혼란 방지 |
| 보스 도전 | 현재 일반 전투가 끝나면 보스 시작. 보스 중 일반 침입은 중단 | 부대 체력·카드·결과가 섞이지 않음 |
| 보스 실패 | 재화 차감·시설 파괴·단계 하락 없음. 결과는 닫을 때까지 유지 | 실패 원인을 읽고 고칠 시간 보장 |
| 보스 반복 보상 | 실패 보상 없음, 단계 성공 보상은 최초 1회 | 보스 재도전을 수입 작업으로 만들지 않음 |
| 부대 회복 | 새 구조에서는 판 사이 회복, **‘다음 주 쉼’은 제거 추천** | 자동 반복 횟수에 따라 보스 출진 가능 여부가 달라지는 문제 방지 |

건설 중인 화면에는 수정안을, 전투 재개 후에는 현재 싸우는 배치를 보여 줘야 합니다. 서로 다른 두 배치를 한 판에 겹쳐 보여 주면 안 됩니다. 보스 도전을 예약했다면 **일반 전투 정산 → 수정안 적용 → 보스 시작** 순서입니다.

보스 실패 후 자동으로 일반 흐름으로 돌려보내는 것도 조금 고치겠습니다. **결과를 확인한 뒤 [배치 고치기]·[다시 도전]·[일반 침입 재개]를 고르게** 하는 편이 퍼즐에 맞습니다. 일반 전투 결과만 작은 기록으로 남기고 자동으로 넘어갑니다.

재화는 다음처럼 나누길 추천합니다.

- **금:** 일반 침입의 반복 수입. 현재는 사용처가 없으므로, 이것만으로 “성장하는 재미가 생겼다”고 판단하면 안 됩니다.
- **마석:** 초기 공사비 + 단계별 한도가 있는 일반 운영 보급 + 보스 첫 성공 보상. 현행 **매주 +30을 무제한 반복 지급하는 방식은 변경**합니다.
- **신석:** 납품 등 기존 큰 보상에 유지합니다.
- **경험치:** 자동 반복 횟수대로 무한 성장하게 두면 보스를 기다림으로 넘길 수 있습니다. 첫 시험에서는 고정하고, 이후 반복 성장의 한도를 따로 정합니다.

마석 보급은 못 막는 사람도 최소한 받을 수 있어야 합니다. 그렇지 않으면 건설비를 잘못 쓴 뒤 막힙니다. 반대로 보급만 기다리면 모든 방을 채울 수 있어도 퍼즐이 약해집니다. **단계별 총보급 한도와 무료 문 수정**을 함께 쓰는 이유입니다.

또한 **‘납품 기준 0/5’를 그대로 ‘보스 0/5’라고 부르는 것은 단순한 표시 변경이 아닙니다.** 현재는 건설·강화만 해도 단계가 오릅니다. 추천은 다음과 같습니다.

> 막대는 **검증 통과 0/5**, 단계 상승은 보스 성공으로만. 기존 가치·전투력 숫자는 배치 참고 정보로 전환.

마지막 보스 성공은 **[납품] 해금**으로 하겠습니다. 현장과 부대를 인계하는 행동은 지금처럼 플레이어가 누르게 두는 편이 좋습니다. 별도 던전 레벨 숫자를 더 만들기보다, 이 검증 단계를 현장 레벨로 표현하면 됩니다.

**카드는 보스 전투에 집중하는 쪽으로 결정 변경을 추천합니다.**

카드 기획 2·3절대로 모든 일반 전투에서 첫 진입 선택과 위기 선택을 띄우면, 자동 흐름이 계속 멈춥니다.

- 일반 침입: 카드 선택 없이 자동 진행.
- 보스: 첫 진입 1회 + 이후 위기 1회, **여러 층 합쳐 최대 2회**.
- 선택·대상 지정 중 타이머 정지, 카드 효과는 현재 층에서만.
- 후보·선택을 저장하고, 같은 보스 재도전으로 후보를 다시 뽑지 않음.
- 이미 승패가 정해진 ⚔ 연출 도중에는 카드를 써서 뒤집지 않음.

2층은 기존 **1층 종료 후 2층 진행**을 유지합니다. 다만 일반 침입의 층 전환은 짧은 안내 뒤 자동으로 넘어가야 합니다. 매번 눌러야 하면 자동 반복이 끊깁니다. 두 층에서 서로 다른 전투를 동시에 돌리는 것은 뒤로 미룹니다.

**(다) 결정론 전투는 유지할 수 있다. 저장 전제는 손봐야 한다**

결정론은 “턴제여야 한다”는 뜻이 아닙니다. **같은 시작 상태·시드·선택이면 같은 결과가 나오는 것**이므로 자동 반복과 양립합니다.

[API 13·14절](C:/project/Dunguen/prototype/d1_demo/API.md)의 핵심 제약은 다음입니다.

| 현재 구조 | 새 흐름에서 필요한 처리 |
| --- | --- |
| 시작할 때 문과 시드로 분대 경로 계산 | 전투 한 판의 입력은 끝날 때까지 고정 |
| `bsave.snap`에 문이 없고 현재 현장 문으로 복원 | 수정안은 별도로 저장하고, 진행 중인 현장 원본은 유지 |
| 강화 효과는 전투 생성 때 적용, 저장 체력으로 복원 | 예약 강화를 복원 때 다시 곱하지 않도록 유지 |
| 전투 정산에서 재화·경험치·단계 처리 | 일반전과 보스전의 보상·단계 상승 규칙 분리 |
| 주 번호와 연결된 쉼·보급 | 전투 횟수와 의뢰 단계로 역할을 나누고 필요한 규칙만 유지 |

일반전은 **전투 번호에 따라 다음 시드**, 보스는 **의뢰·단계에 묶인 고정 시드**를 추천합니다. 일반전을 몇 번 돌렸는지에 따라 보스가 바뀌면 비교가 어려워집니다.

작게 자르는 순서는 이렇습니다.

1. **흐름 시험:** 일반전 자동 반복 + 수동 보스 한 종류. 건설은 판 사이에서만, 카드·방치 없음. 시험용 자원과 성장 고정.
2. **배치와 저장:** 건설 중 정지·수정안 예약, 일반/보스 구분, 보스 단계와 전투 번호 저장. 결과 보상이 한 번만 지급되는지 확인.
3. **첫 의뢰 완주:** 보스 단계 진행·보급·납품 연결 후 새 탭과 현장 화면 적용.
4. **카드 3종 → 2층:** 보스 도전 안에서 붙이고 저장·층 전환 확인.

검사는 특히 **같은 보스 재현, 건설 예약 후 재접속, 보스 결과 직전 재접속, 정산 중복 방지**에 집중하면 됩니다. 저장 구조를 전면 교체할 필요는 없지만, 의미가 달라지는 만큼 기존 v7 전투를 어떻게 마칠지는 명시해야 합니다.

**(라) 방치 보상은 이번 시험에 넣지 않는다**

추천은 **이번 데모에서는 제외, 핵심 흐름이 확인된 뒤 제한된 운영 보상만 추가**입니다.

꺼진 동안 실제 경로·카드·보스·층 전환을 모두 계산할 필요는 없습니다. 나중에는 마지막으로 통과한 단계에 따라 일정 시간까지만 운영 보상을 계산하고, 다시 켰을 때 한 번 지급하면 됩니다.

**보스 승리·의뢰 단계·납품은 오프라인으로 진행하지 않는 것**을 추천합니다. 직접 배치하고 시험하는 핵심 행동이기 때문입니다. 마석을 포함하더라도 앞의 단계별 보급 한도를 공유해야 합니다.

**(마) 1라운드 수렴안에서 바뀌는 것**

③ 회사·현장·군단 3탭은 유지합니다. 자동 흐름은 탭 수를 늘릴 이유가 아닙니다. 일반 침입은 다른 탭에서도 이어지고, 카드 판단이 필요한 보스는 현장에서 진행하면 됩니다.

④ 네 상태는 **운영·건설·보스 도전·보스 결과**로 바꿉니다. 일반전 종료는 별도 결과 화면으로 막지 않습니다. 건설 중 판을 크게 쓰는 원칙은 유지합니다.

⑧ “납품 전에 시운전 1회”는 보스 검증에 흡수됩니다. 대신 개발 시험의 통과 기준을 **같은 자원으로 문을 고쳐 같은 보스 결과를 개선할 수 있는가**로 바꿔야 합니다. 자동전이 한 번 돌아갔다는 사실만으로는 새 재미를 검증하지 못합니다.

| 항목 | 추천 답 | 바뀌는 결정 |
| --- | --- | --- |
| 시간 흐름 | 일반 전투 한 판씩 자동 반복 + 수동 보스 도전 | **변경:** 주 단위 수동 진행 폐기 |
| 퍼즐 중심 | 같은 보스 조건에서 배치 수정 전후 비교 | 보스 구성·시드 고정 추가 |
| 배치·강화 | 편집 중 정지, 현재 전투 종료 뒤 적용 | **변경:** 매주 건설 → 전투 경계 적용 |
| 보스 성공 | 최종 보물방 도달을 막으면 단계 상승, 시간 초과도 성공 | 실제 방어 결과를 진행 기준으로 |
| 실패·회복 | 재화 손실 없음, 결과 확인 후 재개, 판 사이 회복 | **변경:** 다음 주 쉼 제거 추천 |
| 수입·성장 | 일반 수입, 단계별 마석 보급 한도, 보스 첫 성공 보상 | **변경:** 주간 보상 단순 반복 금지 |
| 단계·납품 | 검증 0/5, 최종 보스 성공 뒤 수동 납품 | **변경:** 가치·전투력 자동 단계 상승 |
| 카드 | 보스에서만 최대 2회, 선택 중 정지 | **변경:** 모든 전투의 첫 진입 선택 |
| 2층 | 층별 순차 진행, 일반전 층 전환 자동 | 순차 구조 유지, 전환 입력 변경 |
