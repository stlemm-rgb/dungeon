# 재검수: 구역+시설 vs 고리 길+방 카드 (Codex gpt-6.1-sol medium, 2026-10-19)

둥지짓는 드래곤 요약(refs/ref_nest_dragon.md)과 지난 검수를 근거로 한 Codex 검수 원문. 인터넷 검색 없이 저장소 문서만 근거.

**최종 추천은 ‘고정 세로 구역 6곳 + 시설 선택’입니다. 다만 시설 내부의 실제 미니 미로는 첫 A5에서 빼세요.**
지난 추천의 장점인 고정판·짧은 조작을 유지하면서, 시설로 경로를 바꾸는 재미를 시험할 수 있습니다.
아래는 지정 문서에 근거한 설계 판단이며, 일반 유저의 재미는 아직 검증되지 않았습니다.

| 비교 항목 | 고정 고리 길 + 방 카드 | 세로 구역 + 시설 |
|---|---|---|
| 퍼즐 깊이 | 구성·예산·방 순서의 충돌. 순서 효과가 약하면 숫자 맞추기 | 통과 경로·전력 분산까지 선택. 단, 시설이 모든 문제를 대신 풀면 얕아짐 |
| 유도 재미 | 경로가 고정되어 제한적. 방 효과로 보완해야 함 | 집중 요격·분산·우회를 직접 선택하므로 더 유리 |
| 조작 횟수 | 카드→자리, 기본 2회 | 구역→시설, 기본 2회. 부대·방향을 별도 설정하면 늘어남 |
| 세로 화면 | 고리 가운데 공간과 작은 방 표시가 부담 | 위→아래 진행과 좌우 갈래를 읽기 쉬움. 내부 미로까지 표시하면 다시 복잡 |
| 마왕 요구 | 단일 종류 방의 비율·가치를 설명하기 쉬움 | 혼합 시설은 연결성이 좋지만, 함정 비율의 분모부터 다시 정의해야 함 |
| 개발 비용 | 고정 경로라 상대적으로 작음 | 실제 미니 미로마다 연결·퇴각·재진입·전투·표시 검수가 필요해 더 큼 |
| 반복·정답 고착 | 같은 조합·같은 순서 반복 위험 | ‘입구 함정→강한 대기실’이 만능 정답이 될 위험. 시설 수만 늘려서는 해결 안 됨 |

문서의 기존 침입·요구 판정은 **재사용 후보**입니다. 시설 효과를 기존 입력으로 바꾸는 연결 작업은 필요하며, 실제 재사용 범위는 코드 확인 없이 단정할 수 없습니다.

둥지짓는 드래곤에서 피할 함정은 다음과 같습니다.

- 자료에는 안내소의 역효과, 약한 부하를 둔 대기의 위험, 비싼 돌려보내기가 보입니다. 이를 모두 ‘쓸모없는 시설’로 단정할 수는 없지만, **추천 시설만 남는 구조**는 경계해야 합니다.
- 구역별 전용 시설·상위형·조합형을 그대로 늘리면 긴 목록을 외우는 게임이 됩니다. 구역 제한만으로는 부족하고, 각 선택지의 쓸 이유가 있어야 합니다.
- 상점·여관의 수입과 적 강화는 흥미롭지만, 경제와 전투를 함께 조정해야 합니다. 첫 시안에는 부담입니다.
- 누적 지출+현재 재력 해금, 미끼의 확정 귀환을 그대로 넣으면 해금 계산이나 방어 우회가 핵심 퍼즐을 밀어낼 수 있습니다.
- 길 모양이 달라도 통과 대상·효과 순서가 같으면 제작비만 늘어납니다. **1인 개발에서는 다른 결과를 만드는 시설부터 하나씩 추가하는 것을 추천합니다.**

가장 작은 A5의 제안 범위는 이렇습니다.

- **판:** 390px, 1층·6구역. 입구→좌/우 갈래→중앙→안쪽→보물방 앞→보물. 입구에서 갈라지고 중앙에서 합류하는 고정 연결.
- **표현:** 시설 내부는 칸 이동 없이 효과 순서로 처리. 지도에는 통과 화살표와 함정·몬스터 칸 수만 표시.
- **시설은 4종＋굽은길 방향 2안:** 아래 수치는 시안용 제안입니다.
- **분기:** 입구 전용·무료. 침입자를 좌우에 번갈아 보내며 전투 칸은 없음.
- **굽은길:** 입구 전용·비용 1. 전원을 왼쪽 또는 오른쪽으로 보냄.
- **대기실:** 나머지 구역용·비용 3·가치 20. 몬스터 1칸, 해당 경로로 온 적 전원과 전투.
- **함정 복도:** 나머지 구역용·비용 2·가치 20. 함정 1칸, 해당 경로로 온 적 전원에게 기존 함정 효과 적용.
- **빈 구역:** 무료 통로. 부대는 대기실에 자동 배정하고 별도 배치 조작은 뺌.
- **의뢰 2종:** ① 함정 시설 비율 60% 이상＋가치 100 이상 ② 대기실 비율 60% 이상＋가치 100 이상. 공통 총예산 14.
- **비율:** 입구·빈 구역을 제외한 설치 전투 시설 수가 분모. 두 의뢰는 각각 함정 3＋대기 2, 함정 2＋대기 3으로 구성상 달성 가능.
- **회차:** 3일간 건설→예고된 자동 침입→정산, 마지막에 납품. 하루 최대 2곳 설치·교체, 무료 되돌리기. 정산 수입은 이번 시험 예산에 합산하지 않음.
- **선택 UI:** 구역→가능 시설 최대 3개. 함정 비율·가치·잔여 예산을 즉시 표시하고 결과에는 통과 경로·시설별 기여를 보여줌.
- **뺄 것:** 실제 미니 미로, 함정→대기 혼합 시설, 미끼·경제 시설·해금, 무작위 공급, 직접 설계, 전투 개입, 육성·그림. 여기서 ‘카드’는 시설 선택 UI만 뜻함.
- **끝 기준:** 초보 3명 중 2명 이상이 첫 침입을 90초 안에 시작하고, 경로 선택을 바꾼 이유와 결과 차이를 설명하며 재시도할 것. 같은 배치가 두 의뢰를 모두 통과하지 않고, 한 입구 시설이 항상 우세하지 않을 것.
- 두 의뢰에서 구성만 바꾸고 유도 선택은 그대로라면 시설을 늘리지 말고 경로 효과부터 수정하세요. 이 시험 통과는 장기 반복 재미의 증명은 아닙니다.

파일·코드는 수정하지 않았고 인터넷 검색도 하지 않았습니다.
