# 참고 게임 5: Kairosoft 던전 마을 1·2 (2026-10-22)

> 조사 방식: ① 웹 검색(위키·리뷰) + ③ 총괄 지식. ego 안 씀. 구조만 참고.
> 출처: Kairosoft 위키(1편 설명서·2편), 앱스토어(2편), 닌텐도 페이지, Pocket Gamer·TouchArcade·AppSpy 리뷰, 위키백과

## 무엇
- 2012 안드로이드·iOS(1편), 2편은 iOS 5.99달러(아이패드용 설계, 가로)·스위치. 플레이어는 **몬스터가 득실대는 황야 끝 마을의 촌장**. 가게·숙소를 지어 떠도는 **모험가를 불러들이고 정착**시킴.
- 즉 **우리와 정반대 편**(인간 마을 쪽)에서 본 게임. 우리 "모험가 길드 방문"과 모험가 쪽 설계에 참고.

## 구조
| 요소 | 내용 | 우리에게 |
| --- | --- | --- |
| 모험가 순환 | 나가서 싸우다 → 마을로 돌아와 물건·장비 사고 쉬며 체력 회복 → 다시 나감 | 살아 돌아간 모험가가 **장비를 사서 다시 옴**(재도전 모험단). 모험가 길드 방문 때 그들을 봄 |
| 직업 | 직업마다 능력 보너스 | 우리 전투 성향과 같은 역할 |
| 쓰러짐 | 쓰러지면 동료가 구하거나 아이템으로 부활 | 침입자 쪽 "치유" 성향의 근거 |
| 인기 → 정착 | 마을 인기가 오르면 모험가가 **아예 이사 옴** | 던전 **명성**이 오르면 더 많은·더 센 모험가가 몰려옴(= 수입·위험 둘 다) |
| 지역 7개 | 평원·숲·열대·북극·마법·동양·지하 세계, **지역 마지막 보스를 이기면 다음 지역** | 지역 개척(포탈 열림) 조건 = 그 지역 메인 의뢰 완료 |
| 친해지는 몬스터 | 간식을 주고 기분을 맞추면 동료가 됨 | 우리 사료·부족 계약과 같은 결 |
| 마을 등급(1편) | 별 1~5, 등급마다 조건, 등급이 높을수록 한 달 이벤트 개최 수 증가 | 회사 등급 → 이벤트·의뢰 칸 수 해금 |
| 마을 점수(2편) | 던전 탐사로 점수 → 건물 구매 | 작품집·평판 점수로 시설 해금 |

## 평
- "수익보다 **마을에 오는 한 사람 한 사람**에게 정이 가게 만든다"(AppSpy).
- "같은 공식에 새 가면"(TouchArcade) → Kairosoft 공식은 검증됐지만 반복됨.

## 가져올 아이디어 (CONTENT_IDEAS에 추가)
