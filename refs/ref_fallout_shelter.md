# 참고 게임 1: Fallout Shelter (2026-10-22, 모바일 기준)

> 조사 방식: ① 웹 검색(구조·분석 글) + ② ego로 구글 플레이 스토어 확인(스크린샷 2장). 구조만 참고, 모양·색은 우리 것.
> 출처: 구글 플레이 스토어 페이지 / mobilefreetoplay.com "Deconstructing Fallout Shelter" / GameSpot 2015 매출 기사 / 공략 사이트(gamerevolution, trueachievements, keengamer)

## 무엇
- **원래 모바일 게임** (2015 iOS·안드로이드 먼저, 나중에 PC·Steam). 구글 플레이 다운로드 5천만+, 평점 4.6, 광고 + 인앱 결제, 오프라인 가능.
- 땅속 볼트(대피소)를 **단면으로 보며 층마다 방을 짓고** 주민을 배치해 전기·식량·물을 생산.
- **스토어 스크린샷은 모두 가로 화면** → 세로 화면인 우리는 그대로 쓰면 안 됨(아래 "모바일 세로로 옮기면").

## 구조 (우리와 관련 있는 것)
| 요소 | 내용 | 우리에게 |
| --- | --- | --- |
| 지하 단면 | 위가 입구, 아래로 층이 쌓임, 엘리베이터로 연결 | 현장 = 지하로 파고드는 층별 구역 (사용자 결정과 같은 그림) |
| 방 합치기 | 같은 방을 옆에 지으면 합쳐짐(최대 3칸), 따로 3개보다 생산량이 많음 | 같은 시설을 붙이면 커지는 규칙 |
| 주민 능력치 | 방마다 맞는 능력치(S.P.E.C.I.A.L.), 맞게 배치하면 효율, 훈련방으로 올림 | 몬스터·부대장과 구역 궁합 |
| 생산 타이머 | 5~10분짜리 짧은 생산 → 자주 들어오게 함 | 방치 보상·지점 수입 주기 |
| 서두르기(Rush) | 유료 건너뛰기 대신 **즉시 완료 + 돈, 대신 사고 확률 상승**(화재·벌레). 많이 서두를수록 사고가 잦아 "이쯤 쉬자"가 자연스러움 | 과금 없이 한 판의 길이를 조절하는 장치 → 카드 "도박" 선택지 |
| 사고 | 화재·벌레·습격이 무작위로 | 전투 외 작은 사건 카드 |
| 황무지 탐험 | 주민을 내보내면 돈·희귀 장비를 주워 옴. **제때 불러들이지 않으면 죽고 전리품도 잃음**, 오래 나가 있을수록 부활비 상승 | 지점·파밍: 보내기 → 시간 → 귀환 (손실 회피 긴장감, 단 우리는 부드럽게) |
| 도시락 상자 | 상점 대신 카드 뽑기(자원·돈·장비·희귀 주민). 플레이로도 얻음 → "공정하다"는 평 | 광고 뽑기·보석 뽑기 / 과금은 가볍게 |
| 시즌 | **본 볼트와 따로인 기간 한정 볼트**(테마 장소)를 지어 시즌 보상을 받음 | **우리 신축 + 납품 구조와 같음** → 테마 의뢰·이벤트 부지 |
| 세션 설계 | 강제로 끝내는 에너지 없음. 오래 할수록 보상이 줄어 스스로 나가게 함("유연한 세션") | 우리도 에너지 없이, 방치 보상·카드 수로 조절 |

## 비평 (분석 글)
- **콘텐츠가 빨리 바닥남**: 고수는 약 2주면 할 게 없음(새 방·주민·목표 없이 배치 최적화만).
- **다른 사람과 엮이는 것 없음** → 오래 붙잡지 못함.
- 과금이 가벼워 다운로드당 매출이 낮음(일부러 고른 것).
→ 우리 대응: 납품마다 새 부지·고정 구역으로 반복 방지, 작품집·라이벌 건설사(마족)·랭킹으로 "남과 엮이는" 재미.

## 모바일 세로로 옮기면
- 볼트 단면은 가로로 넓음 → 우리는 **세로로 긴 갱도**(층마다 구역 2~3칸, 아래로 스크롤). 세로 화면에 층이 더 많이 보여 "파고 들어가는" 느낌이 더 잘 맞음.
- 하단 탭 + 위아래 스크롤 한 손 조작.

- 서두르기 = 즉시 완료 + 사고 확률 (과금 없는 세션 조절)
- 시즌 테마 부지: 기간 한정 의뢰로 따로 짓는 이벤트 던전
- 에너지 없는 유연한 세션
