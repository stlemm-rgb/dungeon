# 참고 게임 1: Fallout Shelter (2026-10-22)

> 조사 방식: 총괄이 아는 게임 지식으로 정리(검색 안 함). 틀린 곳은 레퍼런스 확인 때 고침. 구조만 참고, 모양·색은 우리 것.

## 무엇
휴대폰(세로·가로 모두) 방치 경영. 땅속 **볼트(지하 대피소)를 단면으로 보며 층마다 방을 지음**. 주민을 방에 배치해 전기·식량·물을 생산.

## 구조 (우리와 관련 있는 것만)
| 요소 | 내용 | 우리에게 |
| --- | --- | --- |
| 지하 단면 | 위가 지상 입구, 아래로 층이 쌓임. 엘리베이터로 층 연결 | 사용자 결정 "현장 = 지하로 파고드는 층별 구역"과 같은 그림 |
| 방 합치기 | 같은 방을 옆에 지으면 합쳐져 큰 방(최대 3칸) → 효율 상승 | 같은 시설을 붙이면 커지는 규칙 후보 |
| 깊이 = 위험 | 깊이 팔수록 암석을 뚫고 나오는 적(두더지쥐 등) 사고 | 깊은 층일수록 강한 침입자·좋은 보상 |
| 입구 습격 | 약탈자·괴물이 입구 문으로 쳐들어와 층을 따라 내려옴 | 우리 전투(입구 → 아래층 보스·보물방)와 같은 흐름 |
| 주민 능력치 7종 | 방마다 맞는 능력치(힘 = 발전소 등)가 있어 잘 맞춰 배치하면 효율 | 몬스터 부족·부대장을 맞는 구역에 배치하는 재미 |
| 서두르기(Rush) | 생산을 즉시 끝내지만 실패 확률 → 화재·벌레 사고 | 카드 한 장으로 "도박" 선택지 |
| 황무지 탐험 | 주민 하나를 밖에 내보내면 시간이 지나며 장비·재료를 주워 옴. 불러들이는 데도 시간 | **지점·파밍(숲 지점) 방치 수입**과 같은 구조 |
| 도시락 상자 | 카드 뽑기(주민·장비·재료) | 광고 뽑기·보석 뽑기 연출 |
| 목표 3개 | 언제나 목표 3개가 떠 있고 하나 끝내면 새로 | 일일·주간 퀘스트와 같음 |
| 장비 제작 | 재료로 무기·옷 제작 방 | 대장간(장비·인챈트, 나중) |
| 인구 성장 | 주민끼리 생활 → 아기 → 새 주민 | (우리와 결이 다름, 참고만) |

## 가져올 아이디어 (CONTENT_IDEAS에 추가함)
- 현장 단면: 층을 하나씩 **파 내려가며** 구역이 열림, 깊을수록 위험·보상 큼
- 같은 시설 붙이면 합쳐져 커짐
- 몬스터·부대장 능력치와 구역 궁합 → 맞게 배치하면 효율
- 지점 탐험 방치(내보내기 → 시간 → 귀환, 귀환에도 시간)
- 항상 떠 있는 목표 3개

## 우리와 다른 점
- 볼트는 **한 곳을 영원히** 키움. 우리는 **납품하면 새 부지**(신축 + 영업권 판매). 그래서 "현장"은 매번 새로 파지만, 깊이 파는 능력(공방·직급)은 계속 남는 쪽이 맞음.
