## 할 일
1. **보스전·일반전 모두 시간 제한 없음.** 판은 모든 분대가 보물방 도달·퇴각·격퇴로 끝나야 끝난다. `BD.TIME_LIMIT`·`GRID.nextFloorTime`(battle_sim.js 369줄 근처)과 퇴각 원인 `'timeout'`을 정리한다(옛 저장 지점에 남은 값은 읽어도 안 깨지게).
2. 보스 판정은 그대로: **보물방 도달 0 = 성공, 한 분대라도 도달 = 실패.**
3. 화면: 현장 운영·보스 도전의 "남은 시간"(예: `0:48` 막대)을 **지난 시간**으로 바꾼다. 결과 창의 "시간 초과" 원인 글은 없앤다.
4. **안전장치**: 버그로 끝나지 않는 판을 막는 긴 한도(예: 600초)를 코드 안에만 둔다. 화면에 안 보이고, 걸리면 **남은 분대는 보물방 도달(침입자 승, 보스 실패)** 로 처리 → 플레이어가 노릴 수 없게. 걸린 횟수는 측정 때 0이어야 한다.
5. **문 통과 한도 30회(배치 확정 검사)는 그대로 둔다.**
6. **숫자 다시 맞추기**(지시서 `refs/brief_ui_restructure_core.md` 2번과 같은 목표): 1단계는 문 없이 보물방 앞 시설만으로 막힘 / 4·5단계는 문을 옮겨야 막힘 / 문+시설 언덕 오르기 20시드 대부분 납품 / **문만(마석 0)으로는 4·5단계 못 막음**. 필요하면 시작 마석·보급·첫 성공 보상·`BOSSES` 힘을 조정. 측정 표는 `battle_data.js` BOSSES 주석 "3차"에, 숫자는 임시. 평균 전투 시간도 표에 적는다(일반 판이 너무 길어지면 보고).
