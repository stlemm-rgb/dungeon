# 지시서: 흐름 시험 — 일반 침입 자동 반복 + 보스 도전 (core-dev, 2026-10-28)

근거: 사용자 확정 `refs/debate_ds_restructure_2026-10-28.md` "최종 수렴" 1~6 (Codex 2라운드 원문 `..._codex_r2.md`). 한 줄 요약: **주 단위 [다음 주] 대신 일반 모험가가 한 판씩 자동으로 이어 들어오고, 플레이어가 [보스 도전]을 눌러 보스 분대를 막으면 단계가 오른다.** 이야기 설정(의뢰·단계·납품)은 남고, 놀이는 "탑 등반형 방치 + 단계마다 보스".

**이건 손맛 시험이다.** 완성품이 아니다. 목표는 사용자가 폰에서 "같은 보스에 지고 → 문을 고치고 → 다시 도전해 이긴다"를 느껴 보는 것. 되돌리기 쉽게, 작게.

## 맡는 파일
`prototype/d1_demo/` 전부 가능(progress.js·battle_sim.js·battle_data.js·battle.js·shell.js·build.js·shell.css·API.md) + `tools/test_d1_core.py`·`tools/test_d1_flow` 쪽 D1 검사. 이번엔 화면도 core-dev가 **임시로 최소한만** (예쁘게 하지 않음, 나중에 UI 개편에서 다시 만듦). 옛 게임 파일·옛 검사는 건드리지 않는다.

## 만들 것
1. **일반 침입 자동 반복**: 전투 한 판이 끝나면 짧은 쉼(1~2초) 뒤 다음 일반 판이 저절로 시작. 여러 판이 겹치지 않음(한 번에 한 판). 일반 판 시드 = 전투 번호에 따라 다음 시드. 일반 판은 **카드 없음**, 결과 화면으로 막지 않고 작은 기록(토스트·한 줄)만.
   - 일반 판 보상은 지금 정산을 쓰되 **경험치·성장은 시험 동안 고정(주지 않음)**, 마석 주간 보급(+30 반복)은 끔. 금은 줘도 됨. 시험 자원 = q1 시작 마석 그대로(200).
   - "다음 주 쉼"(부대 쉬는 규칙)은 끔. 부대는 판 사이에 회복.
2. **건설은 판 사이에 적용**: [건설]을 누르면 진행 중 전투 일시정지 → 건설 모드. 확정하면 **지금 판을 기존 배치로 마저 끝낸 뒤** 새 배치로 다음 판. (더 쉬우면: 건설 확정 시 지금 일반 판을 버리고 새 배치로 새 판 시작도 허용 — 일반 판은 보상이 작으니. 어느 쪽인지 보고.) 시설 강화도 같은 경계.
3. **보스 도전**: 현장 화면에 [보스 도전] 버튼. 누르면 지금 일반 판이 끝난 뒤(또는 즉시 끊고) 보스 판 시작, 보스 중엔 일반 침입 없음.
   - 보스 = 단계마다 고정 구성 + **의뢰·단계에 묶인 고정 시드**(같은 단계 재도전 = 완전히 같은 침입). 지금 침입자 분대 데이터로 "그 단계에서 가장 강한 분대 묶음"을 만들 것. 데이터는 `battle_data.js`에 표 하나로(단계별 보스 표).
   - **성공** = 어떤 보스 분대도 최종 보물방에 못 들어감(격퇴·퇴각·시간 초과 모두 성공). **실패** = 한 분대라도 보물방 도달.
   - 성공 → 의뢰 단계 +1 (지금 "납품 기준 0/5" 자리 = 보스 검증 0/5). **가치·전투력으로 단계가 오르는 기존 규칙은 끔.** 마지막 단계 보스 성공 → [납품] 열림(납품은 지금 함수 그대로).
   - 실패 → 잃는 것 없음. 결과 화면에 **어디까지 갔나(보물방 도달 분대·지나간 방), 함정 피해, 퇴각 원인** 정도를 간단히 + [배치 고치기] [다시 도전] [일반 침입 재개].
   - 보스 첫 성공 보상: 마석 조금(시험값, 숫자는 주석에 "임시"). 실패·재도전 보상 없음.
4. **시험용 숫자 (밸런스 방침의 작은 예외, 사용자 확정 6번)**: 보스가 **배치에 따라 지기도 이기기도** 해야 한다. 지금 대기실이 너무 셈(HANDOFF 알려진 문제 1). 보스 표 숫자만 맞춰서: 빈 판·대충 지은 판 = 보스에 짐, 문으로 경로를 늘리고 함정·대기실을 길목에 두면 = 이김. 측정 스크립트(스크래치 폴더)로 몇 가지 배치(빈 판·함정만·대기실 1·문 바꿈)를 돌려 표로 보고. 다른 숫자(시설비·대기실 힘 등)는 되도록 건드리지 말 것.
5. **저장**: 자동 반복 중 새로고침해도 이어짐. 보스 결과 직전 새로고침해도 보상 두 번 없음. 단계·보스 시드·전투 번호 저장. 저장 버전을 올릴지는 판단해서 보고(옛 v7 저장은 "회사만 이어 받기"처럼 단순 처리 허용 — 시험이니까).
6. **튜토리얼**: 시험 동안 꺼도 됨(새 흐름과 안 맞는 말풍선이면 끄기). 데모 끝 화면은 마지막 납품 뒤 그대로.

## 안 하는 것
카드(보스전 카드 포함 — 다음 단계), 2층·q2, 방치(앱 꺼진 동안) 보상, 탭 구조 개편(회사·현장·군단 3탭은 UI 개편 때), 보유효과, 예쁜 화면.
