## 2. 캐릭터 화면 (하단 탭 "캐릭터" → 그 자리가 [닫기]로 바뀜)
- **화면 위 약 1/4은 전투가 계속 보임**(보스 체력 271.6k → 579.2k로 진행). 성장 패널이 아래에서 올라와 덮는 방식 → 메뉴를 열어도 놀이가 멈추지 않음.
- 하위 탭 4개: 마법책 · 자매 · 마스터리 · (잠김, 아마 "각성").

| 하위 탭 | 구조 | 재화 | 역할 |
| --- | --- | --- | --- |
| 마법책 | 가운데 두루마리 + 능력 4개(공격·체력·방어·치명타)가 마름모로 배치, "12단계". 아래 줄마다 [레벨업 400] 버튼, 막대 8/10 | 골드 | 기본 능력치 골드 소모처. 4개를 채우면 다음 단계로 넘어가는 듯 |
| 자매 | 위 가로 카드(Lv·이름·장착중/획득/미획득, 해금 조건 "관문 중급병사 달성"·"유저 레벨 50") → 기술(액티브 Lv.10 해금·패시브) → **보유효과**(Lv.10~100 마디마다 영구 보너스) → 레벨 막대 60/250·[업그레이드 💎250]·SP. 일반/고급 자매 탭 | 크리스탈, SP | 캐릭터 수집. 장착은 하나지만 **가지고만 있어도 보너스** |
| 마스터리 | 육각 노드 나무(0/5·0/7·0/15, 갈래 3개). 노드를 누르면 아래에 효과("스킬 데미지 10%") + [강화 SP 150] | SP | 갈래 선택형 영구 성장 |

**공통 틀**: [위: 대상(그림·목록)] → [가운데: 지금 효과·다음 효과] → [아래: 비용이 적힌 버튼 하나]. 하위 탭마다 같은 틀이라 처음 봐도 읽힘. 올릴 수 있는 버튼에만 빨간 점.
**주의할 점**: 성장 재화가 화면마다 다름(골드·크리스탈·SP), 숫자가 크게 부풀어 있음(고급 자매 "60k%") = 방치형 특유의 인플레이션.

## 3. 기술 화면 (하단 탭 "기술", 역시 위 1/4 전투 유지)
| 영역 | 보이는 것 | 역할 |
| --- | --- | --- |
| 장착 칸 "셋팅1" | 5칸(3칸 장착 Lv.1·2·4, 각 [−] / 2칸 자물쇠), 오른쪽 위 프리셋 바꾸기 | 전투에 쓰는 묶음. 프리셋으로 묶음 통째 교체 |
| 총 보유 효과 | "기본 체력·공격·방어 157.5%" | **가진 기술 전부의 영구 보너스 합** (자매 보유효과와 같은 장치) |
| 속성 걸러 보기 | 전체·물리·번개·얼음·…·죽음 아이콘 8개 | 많아진 목록 정리 |
| 기술 격자 (5열) | 아이콘·Lv·**조각 막대 38/42**. 테두리 색 = 등급. [+] 장착 가능 / [−] 장착 중 / 자물쇠 0/1 = 미보유. 조각이 차면 **초록 화살표**(17/15, 5/3) | 같은 기술 중복 = 조각 → 레벨업. 미보유 칸도 다 보여 줘서 모을 목록이 보임 |
| 아래 버튼 | [자동 장착] [일괄 레벨업](빨간 점) | 수집이 많아져도 누르는 횟수 줄이기 |

- 구조 = "중복 조각 모아 레벨업 + 보유만 해도 보너스 + 일부만 장착". 뽑기에서 겹쳐 나와도 버리는 게 없게 만드는 장치.
- 우리 쪽 대응: **던전 카드의 데모 뒤 단계**(카드 기획서 8절 ③ "해금·덱 편성·뽑기는 후속", 사용자 메모 "카드 등급"). 데모는 고정 목록이라 지금은 안 씀.

## 3-1. 동료 화면 (하단 탭 "동료")
- **기술 화면과 똑같은 틀**: 장착 칸 "셋팅1" 5칸(3칸 장착·2칸 자물쇠) → 총 보유 효과(기본 체력·공격·방어 97.5%) → 걸러 보기 → 격자(Lv·조각 막대·[+][−]·자물쇠 0/1) → [자동 장착][일괄 레벨업]. 화면 부품 하나에 데이터만 바꿔 끼운 것.
- 다른 점: 걸러 보기가 속성이 아니라 **역할**(전체·근접·원거리·지원). 등급마다 레벨업 조각 수가 다름(흰 테두리 Lv.7 = 42개, 초록 Lv.3 = 10개). 장착은 레벨 높은 흰 등급보다 **등급 높은 초록**이 들어가 있음 → 등급이 레벨보다 우선.
- 장착한 동료는 메인 전투장에 작은 펫으로 같이 싸움 = 장착이 바로 화면에 보임.
- 우리 쪽 대응: 군단 부대 · 대기실 출진(장착 칸 = 층 출진 한도, 자물쇠 = 아직 안 열린 자리), 역할 걸러 보기 = 종족. **"같은 틀 재사용"은 카드 수집 화면과 군단 화면을 한 부품으로 만들 근거.**

## 3-2. 던전 탭 (하단 탭 "던전" = 흔히 말하는 "탑·일일 던전" 콘텐츠)
- 이 탭만 **전투가 안 보임**(위 상단 바만 남고 전체 목록). 맨 위 공통 시계 "던전 열쇠 충전까지 17시간 5분" = 하루 한 번 채워짐.
- 세로 배너 목록. 배너 하나 = 그림 + 이름 + 왼쪽 위 **보상 재화 아이콘** + 열쇠 2/2 + [입장].

| 던전 | 열쇠 | 무엇을 주나 / 겨루나 | 종류 |
| --- | --- | --- | --- |
| 카드 던전 | 2/2 | 카드(장비 뽑기) 재료 | 재화 농장 |
| 쥬얼 던전 | 2/2 | 보석 | 재화 농장 |
| 자매 강화석 던전 | 2/2 | 자매 업그레이드 크리스탈 | 재화 농장 |
| 용의 굴 | 2/2 | "최고 피해량" 기록 (기록 없음) | 점수 겨루기 (보스에 넣은 피해) |
| 시련의 관문 | 없음 | 등급 "하급병사" → 올라감 | **사다리(탑)**. 자매 해금 조건 "관문 중급병사 달성"과 연결 = 다른 콘텐츠를 여는 열쇠 |

- 구조 = **성장 재화마다 전용 던전 하나** + 하루 열쇠 제한(매일 접속) + 오래 오르는 사다리 1개 + 점수 겨루기 1개.
- 우리 쪽 대응(데모 뒤): 사다리 = **"도전 현장"**(고정 판·고정 침입자, 문 퍼즐만으로 막기, 단계별로 강해짐). 손으로 짠 퍼즐 판은 그림이 적게 들어 1인 개발에 맞는 콘텐츠. 재화 농장·열쇠 제한은 운영형 게임 장치라 데모에 안 넣음.

## 3-3. 콘텐츠 탭 (하단 탭 "콘텐츠")
- **화면 전체가 지도 한 장.** 위 상단 바(전투력·재화)도 사라짐. 부가 시스템을 메뉴 목록 대신 **지도 위 장소**로 묶은 허브.
- 장소 6곳: 제련소(🔒) · 낚시터(빨간 점) · 여신의 축복 · 연구소 · 광산(빨간 점) · 저주받은 영지(🔒). 이름으로 보아 제련소 = 장비 다듬기, 낚시터 = 작은 놀이, 광산 = 방치 생산, 연구소 = 시간 걸리는 영구 연구, 여신의 축복 = 버프, 저주받은 영지 = 별도 모드(추측).
- 장소 모양 = 아이콘 그림 + 이름표 + (자물쇠 / 빨간 점). 잠긴 건물도 지도에 미리 보임 = 앞으로 열릴 것.
- 만드는 비용: 배경 그림 1장 + 장소 아이콘. **기능을 하나 늘리면 지도에 핀 하나 추가**로 끝남.
- 우리 쪽 대응: FEATURES의 **"지역 지도·포탈"(출시, 설계 있음, `docs/GAME_STRUCTURE.md`)**과 비어 있는 **[마계] 탭** 자리. 지점·상점·행사장·심연 도전 같은 "나중" 기능을 마계 지도 위 장소로 하나씩 꽂는 틀로 쓰면 됨. 데모에는 안 넣음.

## 3-4. 상점 탭 (하단 탭 "상점", 출시 단계 참고)
- 하위 탭 5개: 소환 · 잡화 상점 · 패키지 · 기간한정 · 마일리지. 위 재화 줄이 **상점용으로 바뀜**(스킬 티켓 11 · 동료 티켓 23 · 코인 · 다이아, 마일리지 탭은 M 추가). 대부분 판에 하루 초기화 시계(16시간 48분).
- 카드 틀 하나로 전부 만듦: [이름] → [물건 그림 + 개수] → [구매 횟수 n/n] → [가격 버튼]. 가격 버튼 색 = 지불 방법(초록 무료/다이아, 주황 ▶ 광고, 원화).

| 하위 탭 | 내용 | 장치 |
| --- | --- | --- |
| 소환 | 스킬 소환 Lv.3(50/260) · 동료 소환 Lv.2(150/170). 버튼 3개: 15회 ▶광고(3/3) · 15회 티켓/다이아 · 35회 | **소환 레벨**(많이 뽑을수록 좋은 등급 확률↑ 추정). 광고 뽑기 하루 3회 |
| 잡화 상점 | 다이아·카드·코인·강화석·시간 부스터 무료(대부분 ▶광고), 코인은 다이아로 구매 | 광고 = 무료 재화 창구, 하루 횟수 제한 |
| 패키지 | 다이아 꾸러미 1~6(₩1,500~99,000), "보너스 ×2"는 매주 월요일 초기화, 구매마다 마일리지 M. 동료 급성장 패키지 "계정당 1번", 남은 시간 23시간, "×10" 가치 표시 | 첫 구매 2배·한정·남은 시간·가치 배수 |
| 기간한정(일간 패키지) | 일일 무료 선물(다이아 100) + 일일 성장/던전/소환/광폭화/낚시 패키지 ₩1,500~6,000 | 무료 선물로 매일 들어오게 → 옆에 유료 |
| 마일리지 | 결제로 쌓인 M으로 던전 열쇠·강화석·티켓·작살 구매(횟수 제한) | 결제 → 두 번째 보상 |

- 이름이 화면마다 어긋남(던전 탭 "쥬얼 던전" vs 상점 "다이아 던전 키", "자매 강화석" vs "직업 강화석") → 용어 통일은 출시 전 꼭 점검할 일.
- 우리 쪽 대응: `docs/GAME_PLAN.md` "결제"(광고 보고 뽑기 F~SSR, 출시 단계), 과금 재화 **신석**, 광고 대량 출현. **광고 뽑기 하루 n회 + 뽑기 레벨 + 무료 선물 → 옆에 유료**가 가장 가까운 참고. 데모에는 넣지 않음(GAME_PLAN "데모에서 끌 것").
