# 참고: Dungeon Sisters (던전 시스터즈) — 화면 구조 역산

> 2026-10-28. 사용자 스크린샷(휴대폰 세로)만 보고 거꾸로 추측한 것. 실제 규칙과 다를 수 있음. **구조만 참고, 핵심 순환(뽑기)은 가져오지 않음**(총괄 추천).
> 장르: 방치형 자동 전투 RPG. 핵심 순환 = 자동 전투 → 골드·재료 → 장비 카드 뽑기 → 장착·강화 → 전투력 → 스테이지·보스 → 반복.

## 2. 캐릭터 화면 (하단 탭 "캐릭터" → 그 자리가 [닫기]로 바뀜)
- **화면 위 약 1/4은 전투가 계속 보임**(보스 체력 271.6k → 579.2k로 진행). 성장 패널이 아래에서 올라와 덮는 방식 → 메뉴를 열어도 놀이가 멈추지 않음.
- 하위 탭 4개: 마법책 · 자매 · 마스터리 · (잠김, 아마 "각성").

| 하위 탭 | 구조 | 재화 | 역할 |
| --- | --- | --- | --- |
| 마법책 | 가운데 두루마리 + 능력 4개(공격·체력·방어·치명타)가 마름모로 배치, "12단계". 아래 줄마다 [레벨업 400] 버튼, 막대 8/10 | 골드 | 기본 능력치 골드 소모처. 4개를 채우면 다음 단계로 넘어가는 듯 |
| 자매 | 위 가로 카드(Lv·이름·장착중/획득/미획득, 해금 조건 "관문 중급병사 달성"·"유저 레벨 50") → 기술(액티브 Lv.10 해금·패시브) → **보유효과**(Lv.10~100 마디마다 영구 보너스) → 레벨 막대 60/250·[업그레이드 💎250]·SP. 일반/고급 자매 탭 | 크리스탈, SP | 캐릭터 수집. 장착은 하나지만 **가지고만 있어도 보너스** |
| 마스터리 | 육각 노드 나무(0/5·0/7·0/15, 갈래 3개). 노드를 누르면 아래에 효과("스킬 데미지 10%") + [강화 SP 150] | SP | 갈래 선택형 영구 성장 |

**공통 틀**: [위: 대상(그림·목록)] → [가운데: 지금 효과·다음 효과] → [아래: 비용이 적힌 버튼 하나]. 하위 탭마다 같은 틀이라 처음 봐도 읽힘. 올릴 수 있는 버튼에만 빨간 점.
**주의할 점**: 성장 재화가 화면마다 다름(골드·크리스탈·SP), 숫자가 크게 부풀어 있음(고급 자매 "60k%") = 방치형 특유의 인플레이션.
