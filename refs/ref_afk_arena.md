# 참고 게임 10: AFK 아레나 (+ AFK 저니) — 방치형 RPG 표준 (2026-10-22, 모바일 세로)

> 조사 방식: ① 웹 검색(Game Developer 분석·Udonis·Liquid & Grit·Sportskeeda) + ③ 총괄 지식(하단 탭·허브·레벨 공유 등, 틀릴 수 있음). ego 안 씀.
> 출처: Game Developer "Flexible time session design in AFK Arena", Udonis AFK Arena 분석·과금 분석, Liquid & Grit 2021-06 리포트, Naavik AFK Journey 교훈, Sportskeeda AFK Journey 초보 가이드.

## 무엇
- Lilith Games. 첫 돌에 4천만+ 다운로드. 휴대폰 세로 방치형 수집 RPG의 업계 표준. 후속작 AFK 저니(오토체스식 전투·고품질 그림).
- 핵심 반복: **싸워서 보상 → 보상으로 부대 늘리고 강화** (+ 영웅 수집·방치 보상·상점 묶음·뽑기).

## 하단 탭 × 허브 (총괄 지식)
- 하단 탭: **란혼(도시) · 어둠의 숲(지도) · 캠페인(가운데) · 영웅 · 채팅** 류.
- 란혼·어둠의 숲은 **그림 한 장 위 건물 입구**(상점·뽑기·길드·투기장·탑·미궁·현상금 게시판). → 갑부와 같은 "탭 = 장소 + 입구" 구조가 업계 표준임을 확인. 새 입구는 **캠페인 진행으로 하나씩 열림**.

## 방치·세션 설계 (Game Developer 분석)
| 요소 | 내용 | 우리에게 |
| --- | --- | --- |
| 에너지 없음 | 캠페인을 원하는 만큼 → 5분 세션도 1시간 세션도 가능 | 우리도 에너지 없이 |
| 방치 상자 **12시간 상한** | 12시간이 차면 멈춤 → 하루 두 번(아침·저녁) 들어오게 | 지금 우리 방치 보상 상한 8시간 → 12시간 검토 |
| 빠른 보상 | 방치 몇 시간치를 즉시 받기(하루 횟수 제한, 일부 유료, 총괄 지식) | 광고 보고 방치 2시간치 즉시 |
| 일일 과제 점수 | 진행 과제 20점·간접 과제 10점, **20점마다 보상, 100점에 큰 보상**(총점은 100보다 많음 → 골라서 함) | 우리 일일 퀘스트를 **점수제**로: 다 안 해도 됨 |
| 5단계마다 보스 벽 | 막히면 강화하고 나감 → 자주 확인하러 옴. 1주 막혀도 강화 뒤 30단계 전진 | 의뢰 등급의 벽, 막혀도 방치로 뚫리게 |
| 현상금 게시판 | 영웅을 최대 12시간 의뢰에 보내기 | 지점·탐험 보내기와 같은 결론 |
| 메달 초기화 | 상위 경쟁 메달을 주기마다 초기화 → 매출 크게 상승(Liquid & Grit) | 시즌 랭킹 초기화 |
| 레벨 공유(공명 수정) | 상위 5명 레벨을 다른 영웅이 공유 → 새 영웅을 바로 씀(총괄 지식) | 새 몬스터 부족을 바로 쓸 수 있게(친위대 레벨 공유) |
| 방치 상한 늘리기 | AFK 저니: 처음 12시간 → 진행하면 24시간 | 회사 등급으로 방치 상한 증가 |

## 가져올 아이디어 (CONTENT_IDEAS에 추가)
- 방치 상한 12시간(하루 두 번 접속) → 회사 등급으로 늘림
- 광고 보고 방치 몇 시간치 즉시 받기(하루 제한)
- 일일 퀘스트 점수제(20점마다 보상, 100점 큰 보상, 다 안 해도 됨)
- 새 몬스터 부족 레벨을 친위대 레벨에 맞춰 주는 레벨 공유
- 하단 탭 장소 허브의 입구는 진행으로 하나씩 열림 (업계 표준)
