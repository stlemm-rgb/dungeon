# 참고 게임 9: 운빨존많겜 (Lucky Defense) (2026-10-22, 모바일 세로)

> 조사 방식: ① 웹 검색(센서타워·기사·중국 분석 글) + ③ 총괄 지식(화면·등급 연출 세부, 틀릴 수 있음). ego 안 씀.
> 출처: Sensor Tower 블로그(한국 전략 게임 매출 1위, 2024 한국 모바일 게임 현황), 아이뉴스24·아시아경제 기사, 바이징(중국) 분석, 안티치트엑스퍼트 소개 글(홍보성).

## 무엇
- 111%(랜덤 다이스 개발사), 2024년 5월 출시. 휴대폰 세로. **운에 기댄 랜덤 디펜스**.
- 2024년 10월까지 약 460만 다운로드, 인앱 매출 약 4,700만 달러(추정). **매출의 약 80%가 한국**. 한국 전략 게임 매출 1위, 출시 6개월 뒤에도 캐주얼 상위.

## 구조
| 요소 | 내용 |
| --- | --- |
| 소환 | 전투 중 버튼을 누르면 **무작위 유닛** 소환(누를수록 비싸짐) |
| 합성 | 같은 유닛을 합치면 **상위 등급 무작위** → 무엇이 나올지 모르는 두근거림 |
| 등급 | 일반 → 희귀 → 영웅 → 전설 → **신화**(정해진 조합으로 만듦, 총괄 지식). 등급마다 **색·빛 연출**이 달라 높은 등급이 나오면 화면이 번쩍 |
| 도박 | 재화를 걸고 확률로 높은 등급을 노리는 버튼 · 랜덤 룰렛 |
| 밖 성장 | 전투 밖 뽑기로 영웅·아이템, 신화 영웅 강화 |
| 2인 협동 | 둘이 같이 막기 + 채팅 → 다른 캐주얼 디펜스와의 차별점 |
| 난이도 곡선 | 몬스터 체력이 빠르게 늘어 **유닛 하나로는 못 버팀** → 확률을 쫓게 만듦(중국 분석) |

## 왜 통했나 (분석 글 요약)
- **아주 낮은 확률의 아주 큰 보상**이 계속 반복 → "꾸준하지만 짜릿한 도파민".
- 같은 유닛이 겹치면 버프·디버프가 쌓여 합성할 이유가 생김.
- 중반엔 "도박에 쓸까, 신화 강화에 쓸까" 고민.

## 우리에게
| 운빨존많겜 | 우리 |
| --- | --- |
| 등급별 색·빛 연출, 높은 등급이 나오면 번쩍 | **카드·이벤트에도 등급 → 상위 등급은 연출 추가** (사용자 10-22). 뽑기·침입자 등급과 같은 색 체계로 통일 |
| 전투를 "보면서" 가끔 누르는 버튼(소환) | 실시간 전투 보기 + 가끔 카드 넘기기와 같은 리듬 |
| 낮은 확률 큰 보상 반복 | 전설 카드·희귀 침입자(보스) 등장 순간을 크게 |
| 합성 = 무엇이 나올지 모름 | 몬스터 합성(DM) 아이디어와 연결: 합성 결과 무작위 |
| 2인 협동 | 나중 후보: 친구 던전에 내 친위대 지원 보내기(비동기) |
| 한국 매출 80% | 우리 첫 시장도 한국이 맞을 수 있음(한국어 먼저) |

## 가져올 아이디어 (CONTENT_IDEAS에 추가)
- 카드·이벤트 등급 + 상위 등급 연출 (사용자)
- 등급 색 체계 하나로 통일(몬스터·카드·침입자·뽑기)
- 몬스터 합성 결과 무작위
- 친구 던전에 친위대 지원 보내기 (비동기 협동, 나중)
