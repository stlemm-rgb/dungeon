# 지시서: 스토리 흐름도 보기 페이지 (Codex 하청 "솔", 2026-10-24)

목적: 사용자(코딩 초보)가 **장면 파일을 메모장으로 고치고 → 페이지 새로고침**하면 스토리 흐름도가 자동으로 다시 그려지는 도구. 내용(장면 초안)은 다음 작업에서 따로 채운다 — 이번엔 **틀과 예시 4~5장면**만.

## 만들 파일 (이것만, 새 폴더)
`prototype/story/` 안: `index.html`, `story.js`(장면 데이터), `view.js`, `view.css`, `check.js`(node 검사). 그리고 `prototype/index.html`에 링크 한 줄 추가. 다른 파일은 고치지 않는다. 커밋하지 않는다.

## story.js (사용자가 고치는 파일)
- `prototype/d1_demo/lines.js` 머리 주석처럼 **"고치는 법 (코딩을 몰라도 됩니다)"** 안내를 맨 위에 쉬운 한국어로: 덩어리 복사·붙이기, 글은 백틱 안에, 백틱과 `${` 금지, `다음`에 두 개 이상 = 분기, 저장 후 새로고침.
- 모양:
```js
window.STORY = {
  장면: [
    { id: `1-1`, 종류: `스토리`, 제목: `첫 출근`, 장소: `회사`, 등장: `은발 마왕, 소장`,
      배움: ``, 다음: [`1-2`], 메모: `` },
  ]
};
```
- 칸 뜻(주석으로): id(겹치면 안 됨, 예 `1-3` = 1장 3번), 종류(`스토리` · `튜토리얼` · `건설` · `전투` · `분기` · `끝` 중 하나), 제목, 장소, 등장(인물), 배움(이 장면에서 플레이어가 배우는 조작, 튜토리얼일 때), 다음(이어지는 장면 id 목록, 비면 끝), 메모(자유), 선택(분기일 때 `다음`과 같은 순서의 선택지 글 목록, 없어도 됨).
- 예시 4~5장면: 첫 출근 → 첫 현장 도착 → 문 옮기기 배우기(튜토리얼) → 분기 예시(선택 2개) → 첫 전투. **예시라고 메모에 표시**.

## 보기 페이지
- `index.html`이 `story.js`·`view.js`·`view.css`를 불러 **file://로 열려야** 한다(외부 라이브러리·인터넷 없이, 순수 JS + SVG).
- 자동 배치: 첫 장면부터 `다음`을 따라 단(깊이)별로 위→아래, 같은 단은 가로로. 화살표로 잇기. 분기는 화살표에 `선택` 글.
- 종류마다 색 다르게(범례 표시). 장면 상자에는 id·제목·장소 짧게. 누르면 옆(폰은 아래)에 전체 칸 보기.
- **문제 표시**(페이지 위 빨간 줄): 없는 id를 가리키는 `다음`, 겹치는 id, 첫 장면에서 닿지 않는 장면, 알 수 없는 종류. 파일이 깨져서 안 열리면 "story.js 몇 번째 줄 근처를 확인하세요" 안내(가능한 만큼).
- 390px 폰 폭에서도 볼 수 있게(가로 스크롤은 그림 영역 안에서만). 색은 `view.css` 맨 위 변수로, 어두운 바탕.
- 첫 장면 = `장면` 목록의 첫 덩어리.

## check.js
`node prototype/story/check.js` → story.js를 읽어 위 "문제 표시"와 같은 검사, 통과면 `통과: 장면 N개 · 분기 M개`, 실패면 이유 목록 + 종료 코드 1.

## 끝 기준
- `node prototype/story/check.js` 통과. 일부러 `다음`에 없는 id를 넣으면 실패하는지 확인 후 되돌림.
- 지시서 밖 파일 변경 없음(`prototype/index.html` 링크 한 줄 제외). UTF-8(BOM 없이).
- 보고(`-o`): 한국어로 만든 파일, 화면에서 확인한 것(못 했으면 못 했다고), 사용자가 고칠 때 주의할 점 3줄.
