# 지시서: 문 실험 페이지 3차 (Codex 하청, 2026-10-23)

근거: `docs/DESIGN_DOORS.md` 12절. 고칠 파일: `prototype/door_lab/` 안 index.html·lab.js·lab.css·selftest.js 만. 커밋하지 않는다.

1. **분대 습관을 확률로**: 갈림에서 안 가 본 후보 중 미끼 있는 방이 있으면 지금처럼 우선. 그다음, 분대의 **선호 방향**(분대 1 왼쪽·2 오른쪽·3 아래) 후보가 있으면 **60%**(`HABIT_CHANCE = 0.6`) 확률로 그쪽, 아니면 나머지 후보 중 하나를 고른다(나머지끼리는 같은 확률). 선호 방향 후보가 없으면 나머지 중 하나.
2. **시드**: 무작위는 전투 시드 하나로 정해진다(분대·방·갈림 순서로 결정적). 같은 문 배치 + 같은 시드 = 같은 경로·같은 전투 결과(전후 비교 유지). 화면에 지금 시드 작게 표시, **[다른 침입자]** 버튼으로 시드 바꿈(바꾸면 비교 표에 "침입자 바뀜" 표시). `?debug` 경로 선과 실제 전투는 같은 시드로 같은 경로.
3. 분대 표시 글: "왼쪽 먼저" → "주로 왼쪽" 등.
4. selftest: 같은 시드 = 같은 결과, 다른 시드에서 선호 방향이 아닌 선택이 나옴, 많은 시드에서 선호 방향 비율이 대략 60%(갈림이 선호 방향 포함일 때), 미끼 우선 유지, 맵핑 되돌아가기·연결 규칙 기존 검사 유지.

끝 기준: `node prototype/door_lab/selftest.js` 통과, 다른 파일 변경 없음. 결과 보고(`-o`)는 한국어 표.
