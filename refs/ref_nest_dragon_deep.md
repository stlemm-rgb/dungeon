# 참고 게임 심층: 둥지짓는 드래곤 (巣作りドラゴン) — 컨셉·분위기·설정·시스템 (2026-10-22)

> **성인(19금) 요소는 조사·기록에서 완전히 뺐다.** 원작은 성인용 PC 게임이므로 이 문서의 내용 외에는 참고하지 않는다.
> 조사 방식: ① 웹 검색(일본어·영어) + 일본어 위키백과 + 후속 시리즈(巣作りカリンちゃん, Steam 일반판) 상점·리뷰 + 기존 `refs/ref_nest_dragon.md`(사용자 제공 공략 요약) + ③ 총괄 지식(표시함).
> 출처: 일본어 위키백과 「巣作りドラゴン」, 전파미니코게이머·파미통·덴게키·gamebiz 기사(소프트하우스캐라·후속작), Softhouse-Chara 팬 위키, Nookgaming·Steam·OpenCritic(Suzukuri Dungeon: Karin in the Mountain).

## 1. 무엇
- 2004년 6월, 소프트하우스캐라(일본), Windows. 시뮬레이션 + 어드벤처. 개발진이 "실패하면 회사를 접을 생각"이었는데 **체험판 호평으로 크게 성공**, 회사의 대표작이 됨.
- "**시스템과 밸런스가 깊어서 게임으로서 중독성 있다**"는 평. 같은 세계관 작품 여럿, 2019년 이후 시스템을 이은 「巣作りカリンちゃん」 시리즈(일반판 Steam 2024 "Suzukuri Dungeon: Karin in the Mountain"), 2025년 「魔王カリンちゃんRPG」. 회사는 2020년 해산, 권리는 DMM으로.

## 2. 컨셉 (한 줄)
> **"드래곤 중 가장 약한 혼혈 드래곤이, 체면 때문에 거대한 둥지를 짓겠다며 집을 나와, 약소 왕국 옆 산에 둥지를 짓고 쳐들어오는 인간을 막는다."**
- 괴물 쪽 시점의 경영. 주인공이 **약자**라 허세와 생활 코미디가 생김.
- 목표는 정복이 아니라 **"남(같은 종족의 높은 분)에게 보여 줄 만한 둥지"** → 평가받는 집 짓기.

## 3. 분위기 (톤)
- 위키는 톤을 정의하지 않지만, 인물 묘사(요리를 극도로 못하는 마족 지휘관, 츤데레 인물 등)로 보아 **과장된 성격의 코미디 + 인물 중심**.
- 전투·경영은 진지한 숫자 게임, 이야기는 가벼운 소동극 → **"시스템은 진지, 이야기는 웃기게"**의 조합.

## 4. 설정 (세계관)
| 요소 | 내용 | 우리와 비교 |
| --- | --- | --- |
| 몰락한 강자 | 한때 땅과 하늘을 지배한 드래곤이 천계·마계와의 전쟁에 져서 **약 1,000마리만 남음**, 대부분 인간 모습으로 숨어 삶 | 우리 마계도 "사정 있는 세계" 가능: 은발 마왕 집안은 빚더미, 마계 종족들은 던전을 직접 못 지어 하청을 씀 |
| 약한 주인공 | 혼혈이라 드래곤 중 가장 약하지만 **여러 혈통의 힘을 조금씩** 물려받음 | 우리 주인공은 **마계의 유일한 인간** — 약하지만 인간이라 길드에 드나들 수 있음(사용자 결정) |
| 약소국 이웃 | 자원은 많지만 약한 왕국, 주변국과 다툼 중, 북쪽 산에 드래곤 | 침입자 쪽에도 사정 → 모험가 소속(이야기)과 연결 |
| 천적 인간 | **드래곤 슬레이어**(특수한 인간), 드래곤 기사 | 우리 "전설 용사"·천적 침입자 등급 |
| 둥지 = 보여 주는 집 | 재물을 써서 둥지를 **화려하게 꾸밈**, 같은 종족 어른의 기대를 채우는 게 진행 목표 | 우리 **납품 가치 평가·의뢰인 만족**과 같은 구조 |

## 6. 왜 재밌었나 (총괄 분석)
1. **한 번 정하고 지켜보는 전투**: 배치·방침을 정하면 전투는 자동 → 우리 "실시간 전투 보기"와 같은 쾌감의 원형.
2. **손해가 있는 선택**: 돈을 주는 시설이 적을 강하게 함 → 생각 없이 넘겨도 되지만, 알면 더 재밌음.
3. **약자 주인공의 성장**: 가장 약한 드래곤이 남에게 보여 줄 둥지를 갖게 됨 → 성장 체감이 이야기와 일치.
4. **회차 + 인계**: 던전은 새로, 사람·힘은 남음 → 우리 납품 구조가 이미 같은 길(후속작이 더 확실히 그 방향).
5. **체험판으로 증명**: 체험판 호평이 회사를 살림 → 1인 개발도 **짧은 데모를 일찍** 내서 반응 보기.
