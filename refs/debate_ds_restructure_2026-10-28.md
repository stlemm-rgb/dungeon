## 사용자 방향
"Dungeon Sisters를 기반으로 향후 개발한다. 기존 재미(문·경로 퍼즐, 함정·대기실 건설, 매주 전투 보기)와 건설 방식은 포기하지 않는다. UI·탭 구조 전체 개편을 먼저 하고, 콘텐츠는 그 뒤에 채운다."

| 항목 | 총괄 | 이유 |

| 현장 4상태·비율 가변 | **수용** | 내 안의 가장 큰 약점(주 단위 턴과 DS 실시간 화면의 차이)을 해결 |

| 카드·2층 자리 시안 단계 | **수용** | 다시 만들 비용을 줄임 |

| 보유효과 분리 | **수용** | 밸런스·전투 경제 문제. 데모 뒤 |
| 최소 시험 조건 | **합치기** | "밸런스는 나중" 방침은 유지하되, 개편 2단계 확인용으로 **첫 의뢰 시운전 1회(납품 전 전투 1번 필수)**만. 숫자 조정은 하지 않음 |
| 재화 3종 이상 제외 | **수정 수용** | 이미 금·마석·신석 3종. "더 늘리지 않음 + 화면엔 그 화면 관련 재화만"(DS 상점 방식) |

## 사용자 새 제안 (1라운드 뒤)
"시간 흐름도 DS처럼 모험가가 계속 들어오게. 가장 강한 모험가 그룹(보스)이 보물방에 못 들어가면 던전 레벨업(DS 보스 클리어)."
- 총괄·Codex 모두 **찬성으로 바꿈**(1라운드 "주 단위 턴 유지" 철회). "준비 중 멈춘 판"과 "다음 주를 누를 이유" 문제가 함께 풀림.

| 단계·납품 | 납품 기준 0/5 = **보스 검증 0/5**. 가치·전투력 자동 상승 폐지, 마지막 보스 성공 → [납품] 열림 | 수용 |
| 카드 | **보스전에서만** 최대 2회(일반 자동전은 카드 없음) | 수용 (카드 기획서 2·3절 변경) |
| 2층 | 층별 차례 진행 유지, 일반전 층 전환은 자동 | 수용 |
| 결정론·저장 | 유지 가능. 일반전 시드 = 전투 번호, 보스 시드 = 의뢰·단계 고정. 수정안 별도 저장, 정산 1회 보장. 저장 전면 교체는 안 함 | 수용 |
| 방치(앱 꺼진 동안) 보상 | 이번엔 제외. 나중에 제한된 운영 보상만, 보스·납품은 오프라인 진행 안 함 | 수용 |
| 대기실 너무 셈 | 보스가 대기실 하나에 늘 막히면 시험 불가 → 시험용 보스는 **배치에 따라 이기고 지는 정도로만** 조정 | 수용 ("밸런스 나중"의 작은 예외) |
| 개발 순서 | **UI 전체 개편보다 흐름 시험 먼저**: 같은 보스에 실패 → 문 수정 → 재도전 성공 한 바퀴 | 수용 (총괄 "값싼 시험"과 같음) |
